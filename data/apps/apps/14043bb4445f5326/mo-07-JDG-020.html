Israyɛll nebã zaba ne Benzame nebã
20
1 Israyɛll rãmbã fãa yii sẽn sɩng ne Dan hal tɩ ta Bɛɛr-Seba la Galaad tẽngã me n tigim taab Zu-soabã taoor Mitspa. 2 Israyɛll kãsem-dãmbã fãa tigma ne Wẽnnaam nebã. Yaa tãb-biis tus kobs-naas sẽn kẽnd ne nao n tar sʋʋse. 3 Benzame nebã wʋmame tɩ Israyɛll rãmbã tigma Mitspa. La Israyɛll rãmbã sokame n dat n bãng yel-wẽng kãng sẽn ya to-to.
4 Levi rao ning pag b sẽn kʋ wã yeelame yaa: «Maam ne m pagã kẽnga Benzame Gibeya n na n tɩ gãande. 5 La Gibeya nebã waa ne yʋngo n wa gũbg roog ning mam sẽn be wã n dat n kʋ maam. Bãmb modga mam pagã n gãand-a t'a ki. 6 Mam beesa m pagã n tʋm Israyɛll zĩisã fãa n na n wilg yel-beed ning sẽn maan Israyɛll pʋgẽ wã. 7 Yãmb fãa sẽn ya Israyɛll neb n be ka wã, mam kotame tɩ y tags yellã n ges y sẽn na n maan to-to.»
8 Nebã fãa yika wakat a ye n yeel tɩ bãmb ned baa a ye ka na n le kuil a yir ye. Bãmb yeelame yaa: 9 «Yaa woto la d na n maan Gibeya. D na n maana poeere n kẽng n tɩ zab ne Gibeya nebã. 10 Bɩ d yãk Israyɛll buudã fãa neb piig piig koabg fãa pʋgẽ, la neb koabg-koabg tusr fãa pʋgẽ, la neb tusri neb tus piig fãa pʋgẽ tɩ b tall dɩɩb n wa kõ tãb-biis nins sẽn na n kẽng n tɩ sɩbg Benzame Gibeya yel-beed ning b sẽn maan Israyɛll pʋgẽ wã yĩnga.» 11 Yaa woto la Israyɛll rãmbã fãa lagem laab ne yam a yembr n tɩ zab ne Gibeya nebã.
12 Israyɛll rãmbã tʋmame n sok Benzame nebã n dat n bãng wẽng ning sẽn maan bãmb sʋkã yelle. 13 B yeelame tɩ b yiis Gibeya nin-wẽnsã n wa tɩ b kʋ n yiis yel-wẽndã Israyɛll rãmbã sʋka.
La Benzame nebã ka sak n kelg Israyɛll rãmbã sẽn ya b saam-biisã ye. 14 Benzame nebã yii b tẽnsã pʋsẽ n tigim taab Gibeya n na n zab ne Israyɛll rãmbã. 15 Wakat kãngã, rẽ tɩ Benzame tãb-biis sẽn yi b tẽnsẽ wã n wa wã sõor taa neb tus pissi la a yoobe, n zãad sʋʋse. La Gibeya nebã yãka gãndaad kobs-yopoe n paas bãmba. 16 Gãndaadã kobs-yopoe wã fãa b sẽn yãkã yaa goaba. Bãmb fãa tõee n lobga kugr ne loaabga n ka yõsg zoobg ye.
17 Israyɛll neb nins sẽn ka Benzame buudã sõor yaa tãb-biis tus kobs-naas sẽn zãad sʋʋse.
18 Israyɛll rãmbã yikame n kẽng Betɛll n na n tɩ sok Wẽnnaam n gese, yaa bãmb buudã bu-bʋg n na n lʋɩ taoor n zab ne Benzame nebã, la Zu-soabã yeelame tɩ yaa a Zuda buudã n tog n lʋɩ taoore.
19 Israyɛll rãmbã yika yibeoogo n kolg Gibeya n sig be. 20 La bãmb sũu tãp n yi n na n tɩ zab ne Benzame nebã Gibeya. 21 La baraare, Benzame nebã yii Gibeya n kʋ Israyɛll neb tus pissi la a yiibu.
22 Israyɛll nebã kõo taab raoodo, n leb n tɩ yals zĩig ning b sẽn yals pipi daarã n na n zabe. 23 Israyɛll rãmbã kẽngame n tɩ yãb Zu-soabã taoor hal tɩ wĩntoog kẽ. La bãmb soka Zu-soabã n dat n bãng b sãn togame n kẽng n le tɩ zab ne b saam-biisã sẽn ya Benzame nebã.
La Zu-soabã yeela bãmb tɩ b kẽnge.
24 Dẽ, Israyɛll rãmbã kenga b sũy n le leb zĩig ning bãmb sẽn da zĩnd pipi daarã n zabã. 25 Rasem a yiibã raare, Israyɛll rãmbã kolga Benzame nebã. La Benzame neba yii Gibeya rasem a yiibã raar n kʋ Israyɛll tãb-biis tus piig la a nii.
26 Israyɛll tãb-biisã fãa le kẽnga Betɛll n tɩ zĩnd Zu-soabã taoore n loe noor n yãb hal tɩ wẽndgã kẽ. La bãmb maana maand sẽn yõogd bugum, la laafɩ maand n kõ Zu-soabã. 27 Israyɛll rãmbã le soka Zu-soabã n dat n bãng b sẽn na n maan to-to. Tɩ bõe, yaa Betɛll la Wẽnnaam kãabg koglgã ra be wakat kãngã. 28 Wakat kãng tɩ yaa a Aarõ biig a Eleyazaar biig a Fine n da ya maan-kʋʋd be. Yẽ soka Zu-soabã n dat n bãng b sãn tog n kẽng n tɩ zaba ne b saam-biisã sẽn ya Benzame nebã, wall b sãn ka tog n kẽng ye.
La Zu-soabã yeelame tɩ b kẽnge. Tɩ bala, beoogo, bãmb na n kɩtame tɩ b tõog Benzame nebã.
29 Dẽ, Israyɛll rãmbã kɩtame tɩ neb kẽer soos n gũbg Gibeya. 30 Rasem a tãabã raare, Israyɛll rãmbã kẽngame n tɩ zab ne Benzame nebã. Bãmb le kẽnga Gibeya tẽngã noor wa b sẽn da maan pĩndã. 31 Benzame nebã yiime n na n tɩ zab ne bãmba, la b zãaga tẽngã. Bãmb sɩng n kʋʋ Israyɛll rãmbã Betɛll ne Gibeya soɛya zutu, la wet pʋsẽ me. Bãmb kʋʋ sẽn kolg neb pis-tã.
32 Benzame nebã yeelame yaa: «Tõnd le rigda bãmb wa d sã da maan pĩndã.» La Israyɛll rãmbã yeelame yaa: «Bɩ y wa tɩ d zoe n kɩt tɩ b zãag ne tẽngã n ta soɛyã zutu.»
33 Israyɛll rãmbã fãa yikame n yi b sẽn be zĩig ningã n kẽng Baall-Tamaar n na n tɩ zabe. La Israyɛll neb nins sẽn soos n gũbg tẽngã yii b sẽn da soond zĩig ning Gibeya tẽn-nabedrã pʋgẽ wã. 34 Israyɛll gãndaadã tus piig b sẽn da yãkã wa n zaba ne Gibeya tɩ zabrã yɩ toogo. La Benzame nebã ka bãng tɩ toog n dat n paam bãmb ye. 35 Baraare, Zu-soabã kɩtame tɩ Israyɛll rãmbã tõog Benzame nebã n kʋ bãmb tãb-biis tus pissi la a nu la neb koabga. 36 La Benzame nebã bãngame tɩ yaa Israyɛll rãmbã n tõog bãmba.
Israyɛll rãmbã targame n bas Benzame nebã, tɩ bõe, bãmb teega neb nins bãmb sẽn da kɩt tɩ b soos n gũbg Gibeya wã. 37 Nin-bãmb zoeeme n kẽ Gibeya ne pãng n kʋ neb nins fãa sẽn be tẽngã pʋgẽ wã ne sʋʋse. 38 Neb nins sẽn soos n gũbg tẽngã da seda ne Israyɛll neb a taabã n yeel tɩ b sãn wa yã bug-zõos sẽn yit tẽngã pʋgẽ, 39 bɩ b lebg n dig Benzame nebã.
Israyɛll rãmbã wẽnemdame n zoetẽ tɩ Benzame nebã sɩng n kʋ Israyɛll neb pis-tã. Bãmb sãmbame tɩ b le tõogda Israyɛll rãmbã wa b sẽn da maan pĩndã. 40 Bug-zõosã sẽn sɩng n yi tẽngã pʋgẽ, Benzame nebã wẽnemdame n ges b poorẽ n yã b tẽngã sẽn dɩt bugum. 41 Dẽ, Israyɛll rãmbã wẽnemdame n na n zab ne Benzame nebã. La Benzame nebã sẽn yã toog ning sẽn na n paam bãmbã, b pelens yɩkame. 42 Bãmb wẽnemdame n tees weoogã, la b ka põs ye. Israyɛll neb nins sẽn da soondã yii tẽngã pʋgẽ n paas Israyɛll neb a taabã 43 tɩ b gũbg bãmb sʋk n kʋ-ba. Israyɛll rãmbã riga bãmb n kʋ hal tɩ ta Gibeya yaanga. 44 Benzame gãndaad tus piig la a nii n ki. 45 sẽn ket-bã wẽnemdame n zoe n dat n kẽng weoog ning Rimmon kugrã sẽn be wã. La b kʋʋ bãmb neb tus a nu sor zugu. La b kel n diga bãmb hal tɩ ta Geba n kʋ neb tus a yiibu.
46 Baraare, Benzame gãndaad tus pissi la a nu n ki. 47 Neb kobs-yoob n paam n zoe n põse n kẽng weoogã pʋgẽ n ta Rimmon kugrã sẽn be zĩig ningã n zĩnd be kiis a naase. 48 Dẽ, Israyɛll rãmbã lebgame n kʋ Benzame nebã sẽn be tẽnsã fãa pʋsã. Yaa nebã ne rũmsã la bõn-vɩɩsã fãa bãmb sẽn yã wã. La bãmb yõoga tẽns nins b sẽn yã wã bugum.
