3 M ba Katr maoore.
 
Daar a yembre, a Wenaab moona we-rũms maoore. Badaare, we-rũmsã na n maoo ne taab yiib-yiibu. La a Wenaab wilgame tɩ we-rũng ning sẽn tõog n yõka a to n lubi, rũms a taabã sõngdame tɩ b kʋ sẽn lʋɩ-a wã, n kõ a to wã. Woto wã, rũng fãa geta yẽ me sẽn sãmbd t’a tõee a soaba, n bool yẽ tɩ a wa tɩ b yõk maoorã.
 
Maoorã raar yibeoogo, a Katr yik n yeela a pagã t’a maneg rʋk n peke, tɩ zẽed na n waame. La a pagã sok-a lame n na n bãng zẽedã sẽn na n yiẽ. T’a Katr togs-a maoorã kibare, ne noor ning sẽn yiisi, n bilgdẽ tɩ f sã n lub f to, fo n dɩt yẽ soabã. La a pagã le sok-a lame : - La yaa, rũmsã fãa suka, ãndã la yãmb tõe n yõk n lubi? Tɩ a Katr leoke : - E'ẽ Gese. M ba Wiuug rãmb fãa ka be be la? Fo we n pek rʋkã la f yõgen bugmã tɩ m ta la m wa.
 
A Katr sẽn ta maoorã zĩigẽ, a mika rũmsã fãa sẽn nan yɛse. Maoorã ra nan ka sɩng ye. Tao bala, yẽ yeelame tɩ yẽ na n yõka maoorã ne Wiuugu. La a Wiuug pa kɩɩs ye. A me sɩd yɩɩ gãnden-gãndem n segd a Katre. B yiibã sẽn ta taabã, tao bal t’a Katr zãka a Wiuug n lobg yĩngri, n bas n gũud-a, la a maandẽ tɩ b wa sõng-a n kʋ a bũmb n kõ-a. La yẽ sẽn nak n get a Wiuug n gũud a lʋɩɩsã, a kala raoogo, n leeb n Iʋɩ zãmbɛɛl tayy. Kell n sɛga a Wiuug me lʋɩɩse. Yẽ kell n lʋɩɩme n bʋʋg a Katre, n tol n dɩk a zʋʋrã n tui u yõ-rotẽ wã, n tar sʋgb n tar sʋgbo. T’a Katr kelemdẽ la a maandẽ : «Yaa zãmbo. Maoor kõn mao ne sʋʋg ye. Mik yẽ ra tẽedame t’a Wiuug tara Sʋʋg n sʋgd yẽndã yõ-rõtã. Mik yaa a zʋʋrã bala.
 
Rũms a taabã sẽn yã tɩ yaa a Katr n be tẽngrã, b yɩɩ wurrr n zoet n watẽ n na n sõng a Wiuugu.
 
La a Katr paam a fʋsgame, n yik n kʋɩ tĩiga, n dɩk a yir sore, n ya burga-burga n baood a menga, tɩ b rig-a n pa paam ye.
 
A sẽn poog zakẽ wã ne tʋʋlem ningã, a pagã bãngame tɩ yellã pa zems ye. T’a sok-a : - Yeelame tɩ wãna? Yãmb pa paam zẽedã la?
 
La a Katr leok-a lame n yetẽ la a sesdẽ : «N-yaoo! Maoorã zĩigẽ wɩngame. Wã me yaa maam n modge. Paẽ dẽ, mam paadẽ-la be. Tɩ a pagã sok-a n na n bãnge, m ba Wiuug rãmb ka zĩnd be la. T’a yeele : «Yaa m ba Wiuug rãmb yẽne la yellã. Neb sẽn yõgd maoor ne sʋʋse!
 
 
Woto sɩd yaa a Katr yã-raoogã ne a tʋʋm-gãnda wã. Fo sẽn nan pa mao n tõoge, n zoe n yet tɩ b pek rʋk la b yõgen bugum. Wa-wa! Sẽn pa kʋ na sɩɩge?
