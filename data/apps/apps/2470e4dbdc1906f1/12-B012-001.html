12 Goam yaa gũusgu.
Tãoos n da be, a yʋʋr a Kõnlingi. A Kõnling nugã ra yaa noog hal wʋsgo. B tẽngẽ wã, ned pa lʋɩ a taoor ne tãoosg ye. We-rũng ra ka be a sẽn pa kʋ ye. La ayo. Beeme : a kʋʋ we-rũmsã buud fãa, sã n ka we-naafo. A Kõnlĩng ra nan ka kʋ we-naaf ye. Ad pa ned yaar n kʋʋd we-naaf ye. La a Kõnling me pa ned yaar ye. A mii we-rũng fãa nug-gãaga, ne a yalẽ. La sẽn paas me, a tãoosda ne tɩto. Tɩt buud toor-toore, a tarame.
Liulg menga, a tarame.
A sa n kʋ rũnga, a rɩkda a nemdã n koose, la a bĩng a gãongã. Woto, a ra tara we-rũng buudã fãa gãongo, sã n pa we-naafo. Rend bũmb sẽn da paoog-a, t’a sɩd da baood ne sũuri, yaa we-naaf gãongo. La b sẽn bilgdã, we-naaf yaa yel-soalem soaba.
Daar a yembre, a Kõnling kẽnga tãoosgo, n tɩ yã we-nag-yãan-kʋdre, ne a biiga, bi-sadga. A biigã ra nan tara kiis a wãn bala. A Kõnling sẽn yã-bã, a sũur yɩɩ noogo, tɩ bala, a raabã na n pidame. A rɩka a bug-raoogã n teeg a bãokã n gẽeg we-naafã n yɩ kaoo, t’a vik n lʋɩ n gãe n tãoos fãss, fãss, fass.
We-naafã biig sẽn yã b sẽn tão a ma wã; a zoeeme n leb kɛɛnga, n tɩ lam tɩɩg n getẽ la a yãbda. We-naafã tẽba woto, n wa kell n ki, t’a Kõnling bʋʋg-a be n sɩng a sɩɩgre, t’a biigã ket n lam n getẽ, la a ket n tar yãbre. Tãoosã sẽn wa n looge, we-naafã biig kẽnga b sẽn sɩɩg a ma zĩig ningã, n tɩ pʋlme, tɩ rẽnd yẽ kʋ a Kõnling n lebse, n dok a sũuri.
Baraar tɛka, a saada ne weoogã, n gũud raar ninga a sẽn na n wa paam tõogo, n kʋ tãoosã.Kaoosg maaname. We-naafã biig lebga bedre. A ninga a yamẽ wa tɩ wakat taame, t’a na n bao n yãk tãoosã yõore.
La maanda a wãna? Gũud-a-la weoogẽ wã bɩ? Bɩ babsd-a-la yiri? La bõe la sẽn dat n dok-a a sũur ka maande? We-naafã biig yãka yam tɩ yẽ na n bʋʋga tãoosã yiri.
A yikame n maan a meng pʋg-sada, pʋg-sad sẽn pid ne rasãnde: zẽeg muddd, nengã poyy, nẽer woto ; n maneg n pãnem gɛda, n kẽnd zelbr-zelbre,tɩ be yamleoogo.
A yaool n gilgdame n dood daasã, n gẽesd tãoosã. A wa n kẽnga tẽng a ye raaga, n tɩ mik-a be t’a koosd nemdo. A sẽn yã-a wã bala, a bãng-a lame. Wã n tõe n pa bãnge? Moos yeelame tɩ sõy sã n yĩm me, biig ma pa yĩm ye. Ned na kʋ f ma tɩ f tudg-a?
Pʋg-sadã sẽn bãng t’a ma wã kʋʋd rooda raagã, rasem a tãab-tãab fãa, yẽ me wata raagẽ wã. A sã n wa fãa, a baood n na n kolga raoã, n dat t’a ro-a. Bilf-bilfã, tãoosã sɩd do-a lame. Wã n tõe n pa ro? Bi-poll bi-neer woto? B zemsa taaba, tɩ tãoosã peeg-a n kul a yirã. B sẽn ta, pʋg-sadã yeelame tɩ yẽ pa rat pĩiri, a pa rat goeele. T’a rata we-naaf gãong n tʋɩ n zĩndi. Tao bal tɩ raoã yiisa we-naaf gãongo, n kɩs-a. Pʋg-paal na kos bũmb n konge? Mik yaa a ma wã gãongo. Bi-puglã sen yã gãongã, a yãbame t’a ninã mo. Tãoosã sẽn sok-a tɩ yaa noog t’a yãbdã, a leokame bala :- We-naaf gãong tẽegda maam sũ-pa-noaang mam sẽn paam m yãadme. Mam sã n yã we-naaf gãong fãa, mam nintãmã rʋʋgdame.
La tãoosã ka yet tɩ ba a fɩ ye. B zĩnda ne taab n kaoose. Pʋg-sadã ra baooda yam ning a sẽn na n maane, n paam n bãng tãoosã tɩt pãng sẽn taẽ.
Daar a yembre, a yeel-a lame :- Yãmb sẽn gõod weoogã, mam yamã pa noom ye. Rabeem n tar maam. Rũng tõe n pogla yãmba. Ka sɩda? Wala rũng sã n ling yãmb n dat n kʋ, yãmb maanda a wãna?
Tɩ tãoosã leok-a :- Mam manesem yaa wʋsgo. Mam tõe n lebga tãmbeoko.T’a le sok-a :- La rẽ poore, rũngã sã n ket n pa basd yãmba, y maanda a wãna?
- Tɩ m lebg pondr wɛ.- La rẽ fãa sã n kell n pa zemse?- Mam lebgda bugum.- La rẽ poore?- Bũmb a ye n kete. Rẽ fãa sã n pa seke, mam lebgda sup.
Tãoosã pa baas a gomdã, la a ma wã sẽn tool n bool-a zag-zage. Mik pʋg-yãangã ra kelgda b sõasgã. A yeela a biigã:- M biiga, ad pa yɛlã fãa n dɩkd n togs sãan ye.
Fo pa mi a ba-rãmba; fo pa mi a sẽn yit tẽng ninga. Rẽ wã yaa, maan gũusg hal wʋsgo.A Kõnling reega a ma wã gomde, n ka togs n baas ye.
Rẽ zugẽ, a ra ket n gõoda a weoogo, n kʋʋd a we-rũmsi.
Daar a yembre, a yikame n kẽed weoogã, t’a pagã yik t’a na n tũume n tɩ wɩɩs raado. B sẽn tawe-raoogã pʋgã, pagã yeelame t’a na n yõsgame n ta taoor bilfu, n bao raadã la a wa. A sẽn tɩ lillã, a tɩ. rɩka a meng yalẽ wã. A tɩ lebga we-naafo, n tees tãoosã bal n fõt n watẽ. Sẽn yɩ lingr ne tãoosã, a pa paam n daool n na n tão ye. Tao bal t’a lebga tãmbeoko. We-naafã taame n ga tãmbeokã n sarem zãnga. A sũurã yikame t’a be be n tar tibri. Wakat-kãnga, tãoosã lebga pondre, n tar loa-loa n babsd tuudã. Zĩig pʋgẽ tɩ we-naafã lebga raobgo, t’a na n vel pondrã. Tɩ tãoosã lebg bugum, n dɩt moogã. We-naafã la sẽn da mi rẽ fãa tiir la. A lebga koom, n kiisd bugmã; Tãoosã zu-noogã, yaa a sẽn pa paam n togs yẽ rabaar yɛngã sẽn ketã. Koomã sẽn kiis bugmã, we-naafã pa le ne bũmb ye. Zĩig pʋgẽ wã, tãoonsã menmame. We-naafã yõka fiisgu, t’a tãntãn-puudã fãa wa yita, t’a tar ne tẽngã gurbu. A lebga wala nag-gãeenga, n zoet yaare, n tar tɩɩsã tãabó, la a gẽesdẽ. A kell n pa yã bũmb ye. A talla woto n wa vik n lʋɩ n ki. Sasa-kãng masã la supĩim sẽn da sel a zʋʋrẽ wã salg n lʋɩ. Mik yaa tãoosã yaoolem dabaar la rẽ. A sẽn da sɩng tɩ sup, n pa baasã, a ra rat n yeelame tɩ sã n wɩnge, yẽ lebgda supĩim. Woto, a le rɩka a yalẽ wã, n le ya ninsaala.
We-naafã pa tõog n kʋ-a ye, la pa paoog-a ye : A zugã wurame t’a rũmã la a kãntɩɩsã fãa feebe, t’a futã pãrse, t'a lebg zũnglgu, n yas n sesdẽ.
 
Ned pa segd n vaag a pʋgẽ yɛl zãng n togs sãan ye. Rẽ me, pag na ro raagẽ n tall n kul woto bala, n pa mi a sẽn yitẽ?
