91 Kpaano kan yugi, o biga n balini.
Si la pintade vole, le pintadeau ne rampera pas.
Kpaano kan yugi, o biga n balini.
92 Yua n pia dubu n bani bu juoni.
C'est le propriétaire du néré qui connaît les graines de son arbre.
Yua n pia dubu n bani bu juoni.
93 Yua n mandi kan mua luoma.
Celui qui transpire ne se plaindra pas de pauvreté.
Yua n mandi kan mua luoma.
94 Dapolo n soa maama kuli o kan cuo mudiga, se o buolu.
Quel que soit sa sorcellerie, la souris n'attrapera pas le chat, sauf ses semblables.
Dapolo n soa maama kuli o kan cuo mudiga, se o buolu.
95 Poandili yaa ye kpakpalibu po, bi todikaaba n yabidi.
Lorsqu'un crapaud est sur un rônier, c'est qu'il a eu beaucoup de soutiens.
Poandili yaa ye kpakpalibu po, bi todikaaba n yabidi.
96 Gbanli yaa ye li kani, i ŋmaami kpendi ti diedi nni.
Quand les chiens ne sont pas là, les singes rentrent dans le village.
Gbanli yaa ye li kani, i ŋmaami kpendi ti diedi nni.
97 Yaa mudiga n ni ki piindi daa nini ku tangu po.
Le chat qui chie et enterre ses déchets n'a pas encore déféqué sur un roche.
Yaa mudiga n ni ki piindi daa nini ku tangu po.
98 Yua n yugi ki kua mi fantama nni go pia yugiyenma.
Celui qui saute dans le feu a un autre saut à faire.
Yua n yugi ki kua mi fantama nni go pia yugiyenma.
99 Tankpaabilie taamo baa tua tanmulongu.
Un cheval sous la garde de deux palefreniers sera un cheval maigre.
Tankpaabilie taamo baa tua tanmulongu.
100 Ŋunbo yaa baa guli yua, o kan le o tuba.
Quand un âne va vous terrasser, vous ne voyez pas ses oreilles.
Ŋunbo yaa baa guli yua, o kan le o tuba.
