987 So a lootii ɓii janano, galle baaba mum sunndoyta.
988 So a nanii araaji mbaawtoke pobbi taa ɗuum haɗe haɓɓude araawa maa.
989 So a nanii inna wo sukunya, anndu ɗuum wo nyo'ere.
990 So a nanii na wi’e: « waɗu ko tawruɗaa baammaa » anndu ɗuum wanaa nguyka.
991 So a nanii suɓa, wo ɗiɗi.
992 So a nanii wo en ngattu ni mawuuri, ɗuum wanaa uwidoynooɓe baaba muɓɓen.
993 So a nanii wo juutu, anndu ɗum wanaa baasal ɗum wanaa nyaw.
994 So a nelii jom hakkillo taa tindin ɗum ko haalata.
995 So a nyaamii safaare lallude yimɓe, tinna mbaawaa nduttam.
996 So a ŋatii mo woyataa, nyiiƴe ma mbaatan.
997 So a reenanii yigoo maa kulle tati, yigiraagu mon duumo : jawdi, debbo, konngol.
998 So a reenii ngesa maa, nga nyaamaama kala to innde araawa yottii innde ma yottoo.
999 So a ronkii waylude renndo, wayla aan ngondaa e maɓɓe.
1000 So a roondoke ceeli, reenta e nyallo dawaaɗi.
1001 So a sappoke goɗɗo fuh, kolli maa tati keddiiɗi ɗi cappe mbi’a: “reenu hoore maa”.
1002 So a settanii ngaari fuh, wo aan ndi artotoo ndi yuwa.
1003 So a siinii riiwondirde e fowru welnu teppere maa.
1004 So a suusaa suundu, maru rawaandu.
1005 So a tawii doodi na suurta, anndu joomum woɗɗaaki.
1006 So a tawii jom galle na fiya mbaggu sukaaɓe mum na kella, feloore walaa e sukaaɓe ɓeen.
