1027 So a yiɗii yiide subaka de subaka, yiɗaama a yi'ataa ɗum.
1028 So a yigganaama caggal nih njiggaa yeeso.
1029 So a yi'ii ɗemngal na metta hakkunde kolli, anndu ko weli ngal tewni.
1030 So a yi'ii dote na ɓurdi, anndu won nde reway laawol.
1031 So a yi'ii gite na ɓurdi, anndu won bonnde.
1032 So a yi'ii goɗɗum na nanndi e kaalisi tura hoccu; so a tawii nafataa, faɗɗu.
1033 So a yi'ii ƴiiƴam e daande foondu, anndu ndu anndana.
1034 So aan artii naati ngayka, gaɗa maa haanaa heddaade yaasin.
1036 So aɗa haɓa e bonnguujo, fila sawru juutundu.
1037 So aɗa hula suundu, maru rawaandu.
1038 So aɗa nyo’a fuh, ta waam yeeƴitaade.
1039 So aɗa remana ronooɓe ma, waɗu weeti hoota.
1040 So aɗa sonna ɗowgi faa jemma warii fuh, wantir.
1041 So aɗa yiɗi anndude neɗɗo, ndaaru jahdo mum.
1042 So aɗa yiɗi ɓernde bonnde yah wuro muugaaɓe.
1043 So aɗa yiɗi gonɗi yah wuro rewɓe.
1044 So aɗa yiɗi lamɗam, yah maayo geesi.
1045 So aɗa yiɗi yiide ŋappere esa, haalan ɗum ko yiɗi.
1046 So aɗa yigganee caggal, yiggu yeeso maa.
