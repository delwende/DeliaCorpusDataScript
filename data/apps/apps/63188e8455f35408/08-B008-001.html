1047 So Alla wi’ii ma teenoy de a wi’ii wo a ƴoogowan, a hanndinan ni : leɗɗe ngaddoytaa.
1049 So anndal rimii majjere, anndu ngal ɗaatay.
1050 So araawa rimii puccu wannii banngaaro.
1051 So araawa wi'i waɗɗataake, to yahdaa kiite fuh naa hawe.
1052 So ba dawii wuro waaldi, wartii wuro waaldi, mayii woyaama yo mbooka.
1053 So baaji njiɗɗaa fuh, reento e ɗooki.
1054 So bahe mbuldii, gooto fu nyippataanaa nde mum.
1055 So ɓaŋaaɗo waɗɗinaaka du ta ronndinee kirke.
1056 So ɓe na mbasa, ɓe na uwa, ka yaajan de ka luggataa.
1057 So beero feewndoke wuro , tagu mum wi'a ɗum taa ɓooy toon :”mi waran mi tawe toon“.
1058 So beero fiyaama hello, yo kam yawaa, kaa so daasaama yo beero mum yawaa.
1059 So beero fiyaama nder galle wo beero mum yawaa.
1060 So ɓeyɗo wi'ii gollataa, naa ɓiɓɓe mum ekito nguyka gilla ekitaaki ladude.
1061 So biɗɗo barkinii wo ɓii men, kaa so boni, wo ɓii maani.
1062 So ɓiɗɗo na wadda e baaba mum asayeeje anndataa nyannde jeyti.
1063 So ɓiɗɗo rimaama debbo nafaay, nde rimanoo gorko du nafataa.
1064 So bojjel na waawi "kuluujaa" walaa ko heddi ɗum gaɗa wuro.
1065 So bone heɓii ma lummina, so a teetoke du doggu.
1066 So bone mawnii, haala famɗan.
