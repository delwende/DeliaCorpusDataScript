1067 So bonnde na wara ni, wara kam tan, ta wii so wanaa warda e koreejim.
1069 So bumɗo wi’ii na dawa, naniraynaa ɗowoowo mum.
1070 So bumɗo wi’ii nanngee buubi fu, won gonɗi e junngom.
1071 So bumɗo wi’ii waran hiiro maa, tijja ɗiɗo.
1072 So ceŋele keɓii mbeɗu, keɓii ɗo ɗaano.
1073 So cofal jokkii ƴoogoowo fuh, wo yi’ay cokkoowo.
1074 So cofel saloke kus, nanan papap.
1075 So conndi suurtii fuh, wo gawri mum uurtata.
1076 So daande taƴii, ni nyaw gite cellii.
1077 So ɗaaniiɗo fiyaama, won ko waɗuno gilla ɗaanaaki.
1078 So daɓɓel ɓaŋii taƴel, ɓe ndima ndoombel.
1079 So debbo aawii pinndi, wo gonɗi yarnirta ndi.
1080 So debbo e gorko nanndindinaama, ko woni heen fuh sooɗay.
1081 So debbo famɗii nodditoo manngu, so mawni nodditoo cukaaku, so naywii nodditoo waliyaaku.
1082 So debbo maa suwtoke, hokkii ma no ɗaanoroɗaa faa koyɗaa.
1083 So debbo na nodditoo ndimaaku na haani tawee gorum wondi.
1084 So ɗeɗɗaaɗo wi’ii jam, curooɓe njeccoo.
1085 So ɗemngal soñii ɓira bonnde.
1086 So ɗemngal hunyoke fuh, hakkillo sora.
