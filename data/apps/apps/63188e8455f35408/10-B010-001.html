<<    <     1087 So demoowo     1     >    >> 
1087 So demoowo hellondirii juuɗem, anndu o yoppii jalo.
1088 So dene paɗɗaama e yiite, wootere fuh hoorem.
1090 So ɗiilere wurtinii ngaandi, arsuke joomum hantoke.
1091 So ndiyam wudday demmbataa.
1092 So duɗal duncataake doccan.
1093 So eede ndimii ƴibbe, waannii giisoore.
1094 So falfaaje ndimii caɓɓulle wannataanaa pooli.
1095 So fayannde ƴuufii fuh, e mum rufata.
1096 So fewre dawii, de goonga hirndii fuh naa hewtoy ɗum.
1097 So fewre naatii e noppi hemre na tiiɗi wurtinde.
1098 So fitina ɗaanoke yo Alla huɗu pindinɗo ɗum.
1099 So fodoore hawrii e yamiroore dabare bonan.
1100 So fowru hoyɗii wartii wuro, wo waatude mum ɓadii.
1101 So fowru hoyɗii waɗɗoke nyiiwa, hoyɗii saatem.
1102 So fowru tewnitii jokolle fuh, wo e yahdum yi’i.
1103 So fowru wumii, waatii.
1104 So fure saloke, ni ndaaka ɓiree.
1105 So geelooɗi njalondirii ƴuugeeje nyallan nyaamay.
1106 So ganyo neɗɗo warii ɗum ni nde wootore mayata, kaa so giɗo mum warii ɗum maaya laabi keewɗi.
