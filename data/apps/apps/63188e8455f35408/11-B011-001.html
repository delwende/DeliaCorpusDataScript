1107 So geerte colii nyiiƴe, ɗeen nganaa ŋonyotooɗe ƴi’e.
1108 So gerral ɓuri banndum darnde fuh, wo dow waande darii.
1109 So giɗo maa na fecca pucci fuh, fila kirke.
1110 So ginal wi’ii na awa e yookoode banndum, wanaa liƴƴi yiɗi wo hamre yiɗi.
1111 So go’o bonii, limoore forjii.
1112 So goonga haalaama, bahe ndimmboto.
1113 So gooruwol oonyoke fuh, noora du oonyoo.
1114 So gorko ɓaŋii rewɓe nayo, o jogoo gooto, gooto jogoo o, gooto jogoo hoore mum, seytaani jogoo gooto.
1115 So gujjo hoccii yeeynataa.
1116 So gulle njuurnaama wo puɗay.
1117 So hakkillo yeeyaama sontan.
1118 So hayre faɗɗaama, gooto fuh nannga hoore mum.
1119 So heewɓe tuutii e hoore gooto fay so nde yoolaaki du nde leppan.
1120 So hoggo eggii ko jiga doomi?
1121 So hoolaare eggii wartataa.
1122 So hoolaare duumotono ndiyam defataa liingu.
1123 So hoore moɗii hoore, wo moɗaande ndee tan boni.
1124 So huɗo raɓɓiɗii fuh, njooɗoɗaa de mba'aa ɗum.
1125 So iirtooɓe keewii, woodan nokkuɗo.
1126 So ina dagii ni mi defa, so ina harmi ni mi juɗa.
