1127 So inna wooɗii, baaba wooɗii, ɓiɗɗo bonataa.
1128 So ittoyɗo yiite yaltidii e tonngol, anndu o faltoke kaatane.
1129 So jaado maa sonnaama fuh a yeeyaama.
1130 So jaawle ɗiɗi kawtii bippeele, so na piira fuh tinnondira.
1131 So jaawngal na anndi ɗo jaaɓi cukkuki woni ɓoccintaa nder kooli.
1132 So jaawngal selii wadde toɓɓe ni debbo sela jambaade giɗom
1133 So jappoowo yi'ii ko huli, ɓeydan.
1134 So jawdi laataaki maccuɗo maa fuh, laatoo jooma na golline.
1135 So jawe ceŋilii cengiltii ko kalnoo tan kaalti.
1136 So jogaaɗe mburtoke e galle njiɗngu wi’a ɗum heɗam faa mi wara.
1137 So jokolle remaay, yahan ko ɓuri hoore poluwol.
1138 So jontere na fiiloo kaatane wo defoowo haajaa.
1139 So joote ɓuri hoore wanaa yahdu ittata ɗum.
1140 So jultuɗo yettii won ko suuɗi.
1141 So junngo ɓooyii nder gayka fu wo jam tawi.
1142 So junngo na yiɗunoo nyitte leggal heɓataano.
1143 So junngo nanngaama ni ɓernde miiloto ko gollunoo.
1144 So juuloowo faynii araawa wo jigaaje faynani.
1145 So kaareeje ndimii gelleeje wannii tappooɓe na cowna.
1146 So kaatane njarii bita, duncoowo laaɓataa.
