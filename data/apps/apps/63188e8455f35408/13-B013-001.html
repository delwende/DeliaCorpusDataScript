1147 So kahi boɓɓoke kaɗɗe aawaama, ɗowgi ni dillii kaaɗeefi ka dillay.
1148 So kammbu toɓii kure, nduɗotooɓe keewan.
1149 So ko yiɗanoo fu heɓetee jigawal laatotono hammadi koosaajo.
1150 So konkeeje ndimii ɓiɓɓe kahe waannataanaa baaɗi.
1151 So korral ɓurii busal nyaw jilli.
1152 So kulle tati tawii tati goɗɗe,wo nder majje joomum maayata : majjere e mawnitaare, nyaw e neewaaku, talkaaku e waamre.
1153 So laasol fallaandu taƴaaka fuh, yiitataa ngayka mum.
1154 So laawol juutii fuh, gujjo njooɓaari anndete.
1155 So laɓi welii fuh ngeɗu huuɓan.
1156 So laddeeru yarii gappal, jam mum heɓaama.
1157 So lekki ɓuray ma darnde sornataa ma.
1158 So lewla mooloke e fowru anndu wemmbaama.
1159 So liingu tahtoke, ƴoogoowo ittii dimme.
1160 So lonnoowo wemmboke tuutan e juuɗem watta e ndiyam.
1161 So loonde yoppanaaka ndoondiiɗo, ni yoppanee ndonndanaaɓe.
1162 So maaro selay ferude danyan ɗo hamana ganko.
1163 So maayo heewi deƴƴinto.
1164 So mawɗo hippanaama hippitay nde saakanaa du suɓataa.
1165 So mawɗo towaama duroytaa.
1166 So mawnude lonngere ittii ma e suudu bammaa yahrii ma e suudu yaaye, so a waawii ɓuytu lonngere maa.
