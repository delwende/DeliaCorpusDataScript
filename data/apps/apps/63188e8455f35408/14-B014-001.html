1167 So mbaalu na darii walaa ko nyemmbi bojjim.
1168 So mbaggu welii fu ɓilee.
1169 So mbankuujo ɓaŋii bonnguujo, ɓe ndimataa ndartiiɗo.
1170 So mbuubu jokkii lonnoowo fuh, wo kuttoowo woni yi'ay.
1171 So meselal saamii e woyndu, wo calɗiiru tenkoowo wurtinirtee.
1172 So mi annduno, ɗuum wo konngol nimsuɗo.
1173 So mi siinii nyaamde rawaandu, mi hillaaka hirsaandu e saaɗundu.
1174 So mi yiɗii mi waɗa e so mi heɓii mi waɗa, wanaa gootum.
1175 So mo semtataa ƴeenyii e lekki fuh, mo semtataa jippinta ɗum.
1176 So mooƴuure rimii jahe, waannii cofe.
1177 So moƴƴere yoɓaaka , haanaa bonnee.
1178 So mulgo wi’i hokkee ƴi’al, taa jom nyiiƴe ɓerna.
1179 So naafiki ɗaanaaki taa wuro ɗaano.
1180 So naalanke jaaloke wuro fu, wo hellooɓe njaɓi.
1181 So naange fuɗii, junngo uddataa ɗum.
1182 So ndiyam defii liingu, hoolaare boni.
1183 So nduu na daroo nduu na waata, debereedu e ƴoogaaɗo ceedan.
1184 So neɗɗo ɗaɗi mum fuh laatoke buruuti ko mbaawɗa e mum?
1185 So neɗɗo dawii sammooru jaaɓe semtirtaa turoo hocca.
1186 So neɗɗo fenii na laƴa yeggitan yaaɓa.
