1187 So neɗɗo findinaama doggii won ko waɗunoo gilla ɗaanaaki.
1188 So neɗɗo huunoke huuneere ɓoccooɗe de ƴoonde toɓii ɓinde, dow hoorem ɗe pusata.
1189 So neɗɗo nyaamii haaray, nde ɓiirti du haarataa.
1190 So neɗɗo sinngoke tuttii wo e ɓerndem wartata.
1191 So neɗɗo tamii nyuuƴi waɗtii e hunnduko na anndi ko warata.
1192 So neɗɗo wanyanii donoowo ɗum, e talkaakku mayata.
1193 So neɗɗo wanyii kosam fuh, wo sakiti.
1194 So neɗɗo wi’ii : Alla jaabo du’aa’u, wanaa ɓiyum huɗaa.
1195 So neɗɗo wii naa doggina pucel mum e karawal ngal yi'i fuh, naa pucel mum waatu karaaje kantaaki.
1196 So neɗɗo wi'ii hokkete saayo, ndaaru ka ɓoornii.
1197 So neɗɗo wujoke ƴiiƴam worɓe, lootorto ko fa sela wojjude.
1198 So neɗɗo yehii ɓanngal ngal nelanaaka so helii toon faande, so wi’aama nyoota taa mettina.
1199 So neɗɗo yehii naato, wii na jooɗoo de debbo wii ɗum taa jooɗa dow baaɗa, anndu o heɓay sago makko.
1200 So neɗɗo yiɗii fenude fuh, woɗɗina seedeeɓe.
1201 So neɗɗo yoɓaama nyamaande mum de woyii anndu ko nyamlinoo ɗum wooɗaa.
1202 So ngaari wari na daasa ɓoggol anndu won ɗo liɓi joomum.
1203 So ngeɗu heɗoke dananndi, ɓooyi.
1204 So ngesa reenaaka nyaamete.
1205 So ni a heɓii yigiiwo pewoowo suuɗu ɗum nebam maa.
1206 So ni a nanngii gujjo tep, nannga e dabare tep.
