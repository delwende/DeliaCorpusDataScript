1 A Yamne kibare.
Kom-pugli a tãab n wa n tũ taab n kẽng raad wɩɩsgo.
B sẽn wa n yi n dabdã,
yao-zʋʋgã yeelame tɩ yẽ na n tũume,
t’a kẽem-dãmbã tõdge.
Yao wã yʋʋr la a Yamne.
B yeeɩ-a lame tɩ weoogã zãra wʋsgo,
la a ra tũ ye.
La a Yamne basame tɩ b looge,
t’a soos n pʋg-ba.
B sẽn wa n kẽn n zãage,
la b yaool n bãng t’a soos n pʋgdame,
tɩ b kell n bas-a t’a tũ.
B sẽn tar weoogã kakrã,
n tar sõasgã la b baood raadã,
b wa n menmame.
B ra ka le mi b sẽn beẽ ye.
B ra ka le mi yir sor me ye.
B kẽna yaare,
n wa tɩ yã roog sẽn yas weoogã sʋka.
Kom la ko-yũud sẽn da tar-b yĩnga,
b kẽnga yirẽ wã,
n na n tɩ kos koom n yũ.
Zakã ra yaa pʋg-yãang a ye zaka,
t’a be be n vɩ ne a kamba.
Wĩndgã sẽn da paam n lʋɩ yĩnga,
pʋg-yãangã yeela kom-pugli wã tɩ b pa n gãande,
tɩ beoogo,
b na kuli.
Kambã sɩd saka gõogrã.
Mĩk pʋg-yãangã yaa sõya.
Yʋng sẽn ta tɩ b rɩ n sa,
b kẽeme n na n gũsi.
Pʋg-yãangã ra tara kamb a naase,
t’a gãneg bãmb roogã kɩreng a ye,
n yaool n gãneg kom-pugli wã me kɩreng a ye.
Yʋn-sʋk sẽn ta,
tɩ pʋg-yãangã tẽed tɩ kambã fãa gõeeme wã sasa,
a yikame n saasd a sʋʋga,
n dat n kood kom-pugli wã.
A Yamne yaool n da nan pa gõe ye.
A sok-a lame:
- M yaaba,
yãmb saasda sʋʋg n na n maan bõe?
Tɩ pʋg-yãangã leoke:
- M dat n wãa m maana.
La yaa bõe yĩng tɩ fo yẽ ket n nan pa gõe?
T’a Yamne leoke:
- Yaa m pʋg n pa pid la m ket n pa gõe.
Yiri,
yʋngo b kõta maam nanguri,
tɩ mam wãb n yaool n gũsi.
A sẽn yeel woto wã,
pʋg-yãangã yikame n bao nangur n kõ-a.
A sẽn wãb n sa tɩ kaoos bilfu,
a le wʋmda pʋg-yãangã sẽn le saasd a sʋʋgã.
T’a soke:
- M yaaba,
yãmb saasda sʋʋg n na n maan bõe?
Tɩ pʋg-yãangã le leoke:
- M dat n wãa m maana.
La yaa bõe yĩng tɩ fo yẽ ket n nan pa gõe?
T’a Yamne leoke:
- Yaa m pʋg n pa pid la m ket n pa gõe.
Yiri,
b kõta maam bĩisim,
tɩ mam yũ n yaool n gũsi.
A Yamne sẽn yeel woto,
pʋg-yaanga yikame n tɩ bao bĩis-naare,
n wa kõ-a,
la a gõgnemde:
- Ya n yaa bõe sɩ-lak biig la woto,
n tõt gõeem?
Pʋg-yãangã ne biigã kell n talla woto,
hal tɩ zĩigã wa zʋʋge.
A Yamne wa n yeel-a lame tɩ yẽ rata kamaan-maasa.
Pʋg-yãangã sɩd yiime,
n na n tɩ bao kamaanã.
Sasa-kãng la a nek a kẽem-dããmbã tɩ b teem zĩiga.
Bãmb tɩ gãanda pʋg-yãangã kamb sẽn da gãeẽ wã,
n yaool n tall pʋg-yãangã kamb n wa gãneg bãmb zĩige wã.
A Yamne sẽn bãng t’a maan woto,
a reega kamaanã n wãbe,
la a gũsi.
Pʋg-yãan-sõyã sẽn paam t’a Yamne gũsã,
a yikame n saas a sʋʋgã.,
n kood kãmb a naasã.
Sẽn ya likã,
a pa bãng tɩ yaa yẽ meng kambã la a sẽn koodã ye.
A ra teedame tɩ yaa kom-pugli wã.
A Yamne sẽn bãng tɩ beoogã kolg veegre,
a neka a kẽem-dãmbã tɩ b sãd n looge.
Beoogã sẽn vẽeg zãngã,
la pʋg-yãangã yaool n bãng tɩ yaa a meng kambã la a sẽn kood ne yʋngã.
A sũurã yikame,
t’a yi n na n dig kom-pugli wã.
Kambã me yõka zoees ne weoogã,
tɩ b na paam n põse.
La b wa n yãame tɩ sõyã na n paam-b lame tɩ b kabl n paam n dʋ toɛɛga.
Pʋg-yãangã yaool n da tara bendre.
A taa toɛɛgã tẽngre,
n wẽed a bendrã woto:
Pimpindim pindim-pindim,
bi-pugl-poll yãk n lʋɩ tɩ m dɩk n kõ m kamba,
pidgim pindim.
A sẽn wẽ a bendrã woto,
la bi-pugl a ye sẽn yi yĩngrã n farg n lʋɩ.
T’a rɩk yẽ n dɩglg kɩrenga,
n le wẽ yɛsa:
Pimpindim pindim-pindim.
A talla Woto,
tɩ kom-pugli a tãabã luɩ,
n kell a Yamne.
A sã n yɩɩnde la a pãbd bendrã,
la a Yamne sẽn kuiis toɛɛgã yĩngr n paasde.
A talla woto n wa mik t’a ka na n paam-a ye,
t’a maneg n fo a kalle,
n na n dʋ tɩɩgã n babs-a.
A Yamne basame tɩ pʋg-yãan-sõya ta toɛɛgã yĩngri,
t’a yɩ tao-tao n sigi,
n dɩk a bendrã n wẽ woto:
Pimpindim pindim-pindim,
pʋg-yãan-wɛɛg yãk n lʋɩ tɩ m dɩk n kõ m kẽem-dãmba,
pidgim pindim.
A sẽn wẽ bendrã woto wã,
la pʋg-yãangã sẽn sɩng lʋɩɩse,
n tek n yagle.
T’a le wẽ,
t’a le farg n kolg noorẽ,
n le tek n yagle.
T’a le wẽ yɛsa,
tɩ pʋg-yãangã vũ n wa tẽng bup!
A sẽn lʋɩ wã,
a kiime.
Yɩɩ woto t’a Yamne ne a kẽem-dãmbã na n paam n põse,
n lebg n wa yiri.
