3 Ned fãa gũ a pʋɩɩre.
 
Tẽng a ye n da tar a naaba,
tɩ nebã fãa nong-a.
Naabã me ra rɩta naamã ne zemsgo.
Wẽnnaam me sɩd da ning-a-la barka:
pagba,
a tara,
kamba,
a tara Bark kamba.
N-ye.
Bark kamba,
la ka b fãa ye.
A ye n da ya bi-tõtre.
Rẽ me,
a le ya sũ-ki-neda.
Ned sã n paam bũmbu,
zabd-a lame.
La bũmb ning sẽn wa n tɩ zabd-a n yɩɩda,
yaa tɩ b ba wã kũum poore,
naamã na n põsg-a lame.
Rẽ yaa vẽenega,
yẽ sẽn pa kãsmã.
La a sũ-kiirã pʋge,
a ma wã ra sõngd-a lame,
la a pirsd-a.
Woto wã,
b ra naaga taab n baood b sẽn na n maanega,
tɩ biigã paam naamã n deeg a ba wã nugẽ.
Yaa woto tɩ b ra pugd bagb la tɩt rãmb nao,
n kot sõngre.
 
B wa n tɩ yãa tɩɩm soab a yembre.
Rao-kãng me tɩɩmã sɩd da wita wa bugum.
A sẽn kelg b koeesã,
a sũurã sãama ne-ba.
N sɩd be bʋʋm me.
Yãmb me ges wɛ!
Biig na rat n dɩ rog-n-mik naam t’a ba nan ket n zĩẽ?
La ayo.
Tɩɩmã soab kell n bʋka a koɛɛgã,
n yeel-ba:
- Mam tõee tʋʋmdã,
la yel-tũudg a ye n ya toogo.
Tɩ b yeel t’a we n togse.
Tɩ tɩɩmã soab yeel-ba:
- Mam tõe n sõnga yãmb ne tɩɩm,
tɩ biigã paam a ba wã geere.
La tɩɩmã tũuda ne yʋʋm piig la a nu yɩbrgo.
Rẽ me,
yaa yɩbr-vɩɩga.
Yãmb sã n tõog n wa ne-a,
yellã na manege.
 
Tɩɩmã soab sẽn gom n sa,
pagã ne a biigã yik n loogame.
B talla tagsgo,
n bʋgsd bãmb sẽn na n maan to-to n paam yʋʋm piig la a nu yɩbrgo.
Rẽ me,
maanda a wãn n bãng yʋʋm piig la a nu yɩbrgo?
B mak n kongame,
n wa baas n leb tɩɩmã soab nengẽ,
n na n le kos sõngre.
B sẽn lebg n kẽngã,
raoã kõ-b-la tɩɩm.
Tɩɩm sẽn kɩtd tɩ ninsaal tõe n wʋm yɩbrdã goama.
A le wilga biigã rabaar ning a sẽn na n maane,
n yõk yɩbrgã.
A sagl-a lame t’a bao bikalga,
n wʋlg-a rasem a tãabo,
n dɩk-a n zae a yĩngã,
n yaool n kẽng kʋk a yembr tẽngre,
n tɩ gãand n maan wala a kiime.
Yɩbrdã sẽn wat n sõsd kʋkẽ wã sã n yã-a,
b na n sigame n dat n dɩ-a.
Woto,
a paamda a ye n yõke.
Biigã sɩd kẽngame n tɩ maan wala tɩɩmã soab sẽn wilgã.
A sẽn gãandã,
pa kaoos la yɩbrdã wa zomb kʋkã,
n sɩng sõasga.
 
Yɩbrd sã n ta rɩɩb zĩige woto,
yaa kãsmã n dengd n sɩng rɩɩbo.
Tɩ yapã yaool n paam sore,
bãmb me sɩnge.
Pipi yɩbgrã sẽn yɩ laa,
n sigã,
a yɩɩ gegeng-geng n kolg iiã,
n yaas n ges-a pemm,
n yeele:
- Mam yʋʋm pis-nu la woto,
la mam nan ka yã yãoã buud ye.
Mam nan ka rɩ yãoã buud ye.
A sẽn yeel woto,
la a sẽn yɩk n looge.
Ye sẽn loogã,
la a to me sẽn sigi.
Yẽ soabã me kolgame n dong a yublã n gese,
n bas n yeele:
- Mam tara yʋum pis-naase.
La mam sẽn yi m ma gelle tɛka,
mam nan pa ri yãoã buud ye.
Pa rũndã la m na n sɩng ye.
Yẽ me sẽn yeel woto,
la a sẽn be yɩkrẽ.
Sẽn tarẽ n tarẽ wã,
yɩbrg a yẽ n wa n yɩk n sigi,
n tar yeng-yeng n dabda.
A sẽn ta wã la a sẽn yeele:
- Ad tõnd kãsem-dãmbã yaa rabɛɛmba.
Rɩɩb me n wa n be ne m zɩ n yã.
Bi zɩ n yã tõta yãabo.
Mam sẽn wa moog yʋʋm piig la a nu la woto.
Mam sẽn dɩ bãmbã buud ka be tɛk ye.
A pa yã n gom n sa la a be biigã yãoog zug rʋʋbẽ,
t’a na n kolg n geok a nifrã,
tɩ biigã yɩ-a zã,
n gãd a naoã.
T’a tar pig-pig n dat n fãage.
La pa tõe n fãag wɛ.
Biigã talla yɩbrgã n leb tɩɩmã soab nengẽ n na n tɩ kɩs-a.
La tɩɩmã soab yeel-a lame t’a togs yẽ yella sẽn yɩ to-to.
Tɩ biigã togs-a fãa,
ne yɩbrdã goamã.
Rẽ masã la tɩɩmã soab yeel-a:
- M biig sõngo,
kelg neere:
bõe yĩng tɩ fo paam yɩbr-kãngã soabã n yõke?
Bõe yĩng la a yõorã sẽn na n yɩ koɛɛgã?
Pa a sẽn tẽed t’a minim la a pãng yɩɩda sẽn deng-b yẽ n dogã?
Rẽ wã yaa,
maan dũni rabeem,
la f maan gũusgu.
Yik n kuli.
La rũndã tɛka,
yãk tags-beed f yamẽ wã.
Yãk sũ-kiĩr f yame wã.
Ad Wẽnd sẽn na n kõ foo bũmb ningã,
rẽnda bal la fo so.
