4 A Yamyɩɩd kibare.
Tẽng a ye n da be,
n boond,
tɩ Ralingnaaba,
tɩ b kʋʋg n boond faag-faag tɩ Ralingi.
Bũmb ning sẽn wa ne tengã yʋʋrã me,
yaa tɩ tẽn-kãngã ned ka segd n maan bũmbu,
t'a pa togs naab ye.
Naabã wa n yiisa noor menga,
tɩ biig sã n doge,
a yʋʋrã kũun pa segd n ling yẽ ye.
Fo me pag sã n doge,
tɩ yaa pag tɩ yaa raoa,
fo kẽngda na-yirã,
n tɩ reeg biigã yʋʋr be.
Talla woto,
t'a Yellpagindim pag wa roge.
A roga bi-ribla.
Biig sẽn tar rasãnde,
t’a Yellpagindim ne a pag a Wẽndtõe sũur ya noogo.
Yaẽ bũmbu,
b pa baoẽ b yamleoog yʋʋr n pʋd-a.
La tẽngã naab noor deegr yĩnga,
rasem a tãab poore,
yibeoog pĩnda,
b rɩka na-yirã sore,
n na n tɩ bõs tɩ b yãk yʋʋr n kõ biigã.
B sẽn yi wã,
b pa yã n zãag ye.
Bi-pɛɛlgã zĩnda a ma wã poorẽ n yeele:
- Lebg-y tɩ d kuli.
Lebg-y tɩ d kul tɩ mam zoe n tara yʋʋre.
Wao!
Ad wã yaa dũni yel-soalma !
Rasem a tãab biig sẽn gomde?
Rẽ me,
a pipi goam yaa naab noor kɩʋʋsgo.
Biigã ba ne a ma sẽn wʋm woto,
rabeem kẽ-b lame.
La ba wã soka biigã:
- Tɩ fo yʋʋr la a bõe?
Tɩ biigã leoke:
- Mam yʋʋr la a Yamyɩɩdnaaba,
la bool-y maam t’a Yamyɩɩda.
Nebã a yiibã yalsa wʋmm,
n pa mi b sẽn maandg ye.
Yell wa yã!
B wa n baas n sɩd lebg n dɩka yir sore.
B kulame n tɩ be yiri,
n vɩ b beoog-beoog fãa vɩɩmã,
n tʋmd n dɩtẽ,
la b gʋʋnd b kamba.
Yʋʋm wa n loogame.
T’a Yamyɩɩd zẽk bɩʋʋngo,
n sɩng zoet n deemd ne a taaba.
T’a ba-rãmb mi n tʋm-a,
t’a ya lomb-lomb-lombe,
n kẽnd la a watẽ.
Talla woto t’a yʋʋrã wa lʋɩ tẽngã naab tʋbre.
Tɩ naab sũurã yiki.
T’a sok a kug-zĩidbã:
- B yet tɩ Raling ka,
biig n be t’a yʋʋr la a Yamyɩɩda.
Roga rabʋre?
Ãndã n kõ yʋʋrã?
Ãndã n so tẽn-kãngã n yɩɩd maam tɩ yell a woto wa lingd maam?
Bul n yaa ãndã biĩg sẽ?
Tɩ ned a yembr yeel tɩ yaa a Yellpagindim ne a Wẽndtõe biiga.
Tao bal tɩ naab tʋmame tɩ b tɩ bool a Yellpagindim t’a wa na-yirã,
nif ne a kãmsg pʋge.
Sɩd yɩɩ woto,
t’a Yellpagindim yɩ zok-zok-zoke,
n wa ta n wõgemd n pʋʋse,
la a soke:
- N-Naa!
Tɩ yãmb n boonde?
M waame.
N-naa!
TƖ naab sok-a:
- Fo biig la Yamyɩɩdã soaba?
- Naaba,
n-ye.
- Ãndã n pʋd biigã yʋʋre?
- Naaba,
ad-y yaa biigã menga.
- Biigã menga ?
Fo lebga gãeeng la?
Bɩ maam la f rat n daase?
Sẽn ya a soab me,
fo na bãng tɩ Raling ka,
maam n so tẽngã.
Fo na bãnge,
tɩ mam noor ka kɩɩsd ye.
Yik n kuli,
la f gũ m koɛɛga.
A Yellpagindim yika wʋmm,
n tar lama,
lama,
lama,
n teesdẽ,
t’a sũur pibda.
Yel-kãngã na n baasa wãn-wãna?
A sẽn ta yirã,
a togsa yellã a pag a Wẽndtõe,
tɩ b fãa naag taab n zĩ ne sũ-sãanga.
Rasem a wãn poore,
zaab-noor sasa,
naab tʋma neb ne kazẽega,
tɩ b tɩ kɩs a Yamyɩɩd ma wã,
t'a reeg n los tɩ lebg kae t’a kõg rãam,
tɩ bãmb pʋʋsa b susoaaga,
tɩ ya vẽtembeoogo.
La bãmb data rãamã n kõ nebã.
La b le paas t’a modg tɩ ra yɩ rã-ãbg ye.
Pa no-rɩkre?
N dat tɩ pagã yet t’a pa tõe tɩ b paam n sɩbg-a?
Pagã reega Kazẽegã n dɩgle,
t’a sɩdã wa t’a wilg-a la a togs-a,
tɩ b naag taab n zɩ n bʋʋdẽ.
Yel-kãngã maanda a wãna?
Neb a yiibã sẽn nan yeeg neng n zĩe wã,
la a Yamyɩɩd sẽn wa n ta n sok-ba:
- Yeelame tɩ bõe Tɩ yãmb y yiib fãa boog n zĩ woto?
Ned n ka keem la,
bɩ ned n maan kaalem?
T’a ma leoke:
Pa kũum ye,
la ne kũum zem taaba.
Ad Kazẽegã sẽn dɩge.
Naab n kɩs tɩ m kõg rãam tɩ yɩ beoog rãam.
Biigã sẽn wʋmã,
a yeela a ma wã ne a ba wã:
- Sã n zemsa woto bal bɩ y bas tɩ ka yel-kẽgeng ye.
Mam na n tɩ sõsa ne naab la m wa.
A sẽn gom woto,
la a sẽn kẽ rooge n lebg n yi,
n dɩk na-yirã sore.
T’a ba-rãmb zĩ n bʋʋdẽ:
hãnd naab na n tɩ basa b biigã t’a wa laafɩ?
A Yamyɩɩd taame waa,
n pʋʋs naab ne waoogre,
la a yeel-ba:
- Naaba,
yãmb sẽn kɩs m ma Kazẽegã yaa,
a losa kae wã,
n dʋgle,
la wamd kae n vaagd kõgr ye.
Yaa rẽ tɩ m watẽ tɩ y sõng-ma.
Ad kãand biisi.
M kotame tɩ y reeg yaa,
n bʋd zaabrã tɩ yi n wom yaa,
tɩ y kɩɩb tɩ m paam wama.
Ad yaa wamã bal la m ma zu-loɛɛga.
La bũmb sẽn be,
wamã sã n pa yɩ wam-wẽgdo,
Wẽnd sõngre,
rãamã me yɩta sõama.
Tɩ naabã sũur puugi,
t'a leok tɩ kãand kõn bʋd rũndã,
t’a yi rũndã,
n wom dũndã,
tɩ b paam wam ye.
Rẽ la a Yamyɩɩd na n yeel naaba:
- Ad yaa rẽ sẽn pa tõe wã,
la m ma me sẽn pa na n tõog tɩ Kazẽegã lebg kae rũndã,
t’a kõg rãam zĩig pʋge wã.
Naab sẽn wʋm dẽ,
a tʋmame tɩ b tɩ reeg Kazẽegã n wa.
La a ra ket n wẽendame bal tɩ yẽ na paam a nin-bãmbã.
Rasem a wãn yel-kãensã fãa loogr poore,
naab kɩtame tɩ b tall loalg n tɩ kɩs a Yellpagindma,
t’a reeg-a n wubi.
A Yellpagindim sẽn mi tɩ yẽ zakã rãmb ne naab yaa wõg-wõgã,
a sɩd pelga a pʋg n na n zã naafã.
Wĩndga,
yʋngo,
a geta naafã yelle,
tɩ bũmb ra wa maan-a ye.
A tõogame t’a nob sõama,
n yɛs yolgemde,
n sɩd tar rasãnde.
Daar a yembre,
naab tʋmame tɩ b tɩ reeg naafã ne a kambã n wa.
A Yellpagindim sẽn wʋm dẽ wã masã,
la a yaool n bãng tɩ sẽn kɩs yẽ naafã yaa sẽn na n bẽd n paam-a.
Nag-raoog na roge?
Wã pa sẽn dat n dõd bũmb bal n paam yẽ n sɩbge?
T’a le zĩ ne yɩɩre,
n pa mi a sẽn kẽed zĩig ning n põs yellã ye.
La a biig a Yamyɩɩd le yeela a baaba t’a ra yaees ye.
Tɩ Wẽnd sã n sake,
yellã na n manegame.
A Yamyɩɩd basame tɩ yʋn-sʋk ta,
tɩ nebã fãa kẽ gõeem,
tɩ tengã fãa ya sɩɩ,
t’a yi n dɩk a soang n palge,
n tar soa,
soa,
soa,
n dabd na-yirã.
Pusg n yɛs naabã sɩmande.
A taame n tar koa,
koa,
koa,
n peesd pusgã.
Naab wʋma bʋʋrã,
n sok tɩ yaa ãndã soab n keed tɩɩg ne yʋngo.
B sẽn yi n gese,
mikame tɩ yaa a Yamyɩɩda.
Tɩ naab sok-a tɩ yaa noog tɩ yẽ wa peesd pusgã sasa kãngã.
T’a Yamyɩɩd wẽ siri,
la a leoke:
- Hũmm.
Naaba!
Ad yaa yʋn-sʋk yel-yãgdem.
M baaba n dog yaa,
tɩ b tʋm-m tɩ m wa pees pusgã n wa tɩ b rʋg n so bi-pɛɛlgã.
Tɩ naabã yeel-a:
Kelg ka biigã !
Ra yaal maam koe!
Yaa bõe goam la woto?
Fo sẽn dogã tɛka yaa,
fo zoe n wʋmame tɩ rao rog yã?
T’a Yamyɩɩd wẽneg n yeele:
- M tõe n bãng tɩ yãmb yet tɩ yãmb nag-raoogã yãmb sẽn da kɩs m baaba wã segd n tara nag-bi?
A sẽn yeel woto wã,
naabã bãnga masã tɩ biigã gom n lub-a lame.
A kɩtame tɩ b tɩ tall loalgã n wa.
La a ra ket n wẽendame tɩ yẽ sẽn sɩbg bi-kãngã bal n be.
Naab sẽn mik t’a pa tõe n bẽd biigã bɩ a ba-rãmbã n paamã,
a yeela a kug-zĩidbã tɩ biigã na n wãa tẽngã.
La rẽ yĩngã,
bɩ b kʋ-a.
B tʋmame tɩ b tɩ yõk-a n wa na-yirã.
A sẽn wa,
b kɩtame tɩ b sui-a yolg pʋga,
n yaool n yãk neb a yiibu,
tɩ b tʋk yolgã n na n tɩ lob mogrã pʋga.
Naab keoog neb a yiibã woto:
- Haya!
Maan-y gũusg hal wʋsgo.
Kõb-wẽn-kãngã sɩlmã la y sẽn mi wã la.
Da maan-y-yã a raabo,
ra kelg-y-yã a goama.
Tɩ lob-y-yã-a mogrã pʋg bala.
 
Bãmbã me sẽn wʋm dẽ,
b vaaga b sor n tar yõarg n dabd mogrẽ wã,
n na n tɩ lob a Yamyɩɩda.
La b yet tɩ Wẽnd pa kʋ naab pa kʋʋd ye.
Mogrã ziig sẽn zãr yĩnga,
neb a yiibã kẽname n wa ya,
n zĩnd tɩɩg tẽngre,
n na n pems bilf la b yaool n yiki.
B wa n nee yĩisr naoor sẽn kaoog t’a keoosd n loogdẽ.
Na yaa tãoos n pogl-a n yaool n pa paam-a bɩ bõe?
Nebã a yiibã basa b yolgã,
n na n dig yiisrã.
B rig-a lame n zãage.
Sasa-kãnga,
Silmiig n wa n loogd ne a niiga,
n tũ tɩɩgã tẽngre,
n yã yolgã sẽn dɩgã.
A ta n dɩka a rasaarã n wẽ yolgã la a gomd a yembre:
- Yaa ãnd soab n yĩm a yolg ka?
A Yamyɩɩd zĩnda yolgã pʋg n yeele:
- Hũmm !
Y maand-m-la pãnga.
N yet tɩ m pa rat n yɩ naaba,
tɩ y rat n modg-m n kõ naam.
Ayo.
M pa rat n yɩ naab ye.
Silmiigã sẽn wum a Yamyɩɩd goamã,
a tẽedame tɩ sɩd yaa ned la b yõk n dat n tɩ kõ naam,
t’a soabã pa rat ye.
Tao bala,
a loka yolgã noore,
t’a Yamyɩɩd yi.
La a yeelame tɩ sẽn ya woto wã,
rẽnd yẽ na n deega biigã zĩiga.
A sɩd kẽe yolge wã,
t’a Yamyɩɩd maneg a noorã n sebg sõama,
la a bas n peeg a niigã n looge.
 
Nebã a yiibã me riga yĩisrã,
n wa mik tɩ b pa na n paam-a ye.
Tɩ b lebg n wa,
n wa tʋk b yolgã,
n le rɩk mogrã sore,
la b gomd woto:
- Haya!
D zẽk naoore.
Mas-masã tɩ d pa ta mogrẽ wã n lobg kõb-wẽn-kãngã la d paamd d menga.
Silmiigã sẽn wʋm goamã,
a bãngame t’a lʋɩɩ yell pʋga.
T'a zĩnd yolgẽ wa n yeele:
- Walaasi mam ka kõb-wẽng ye.
Mam yaa Silmiiga.
Tɩ neb a yiibã leok-a:
- F lebga Silmiig masã?
Bas rẽ la f lebg Marenga.
F yet tɩ f sɩlem waoog laa,
so-kãngã yẽ,
fo kiime bala.
B ra tẽedame tɩ yaa a Yamyɩɩd n maand dabaare,
n teem a koɛɛgã n dat n belg bãmba.
La Silmiigã zĩnda yolgẽ wã n le yeele:
- Ka sɩlem ye.
Mam dat n yɩɩ naaba.
Tɩ b yeel-a:
- Fo rat n yɩɩ naaba?
Ka ne bilf bala,
d sã n lob-f mogrã pʋga,
f kõn tɩ rɩ naam be ne zĩmã,
rendeedã la yẽbsã?
Silmiigã bee yolgã pʋg n tar gõgneng la gãgnengo,
la nebã a yiibã ra ka le kelgd-a ye.
B taa mogrẽ wã n lob-a be faoo.
La b lebg n zãensdẽ n kuiisẽ,
n ta n togs naab t’a Yamyɩɩd yũug menma dũniya.
A Yamyɩɩd peega Silmiigã niiga,
n wa ne yiri,
n wẽ yãgr n ning-ba.
Rasem a wãn poore,
a pẽe bĩisim zembala,
n tʋk n kẽng na-yirã,
n na n tɩ kõ naaba.
Nebã sẽn yã-a wã,
b pɛleng yɩkame.
B ra bʋgsdame:
hãnd pa biigã kɩɩm n wa n na bugs bãmba?
Sã n ya ne naabã menga,
yẽ ra tagsdame tɩ raar ninga,
nebã tek n basa a Yamyɩɩd t’a põse,
la a sẽn lebg n wa wã.
La a Yamyɩɩd taame waa,
n pʋʋs naaba,
la a yeel-a:
- Naaba,
ad m wat n na n bãnga y keelem yaa,
la m pʋʋs m zaamẽ beoogo.
Yãmb maan maam neere.
Yaa sɩda,
yãmb sẽn kɩt tɩ b tɩ lob maam mogrẽ wã,
mik tẽn-noog n be be.
Be rãmbã yãka b laogã bilf bal n kõ maam:
niig koabga.
B yeelame tɩ mam wa reeg naam be menga.
Ka ne rasem a wãna,
m na n lebame,
maam ne tõnd zakã rãmb fãa.
Nananda,
reeg-y bĩisim.
Yaa mam niigã bĩisim.
Naabã sẽn wʋm woto,
a kɩtame tɩ b yõk biigã n pag roogo.,
A yaool n yeelame tɩ b bao yondo,
n sui yẽ zakã rãmb fãa:
na-pagbã,
ne kambã.
Yẽ mengã yaool n kẽe yol-bedr pʋga,
n yet tɩ b sẽb yondã noy sõama,
n wʋk-b n tɩ lob mogrẽ wã.
Bala,
tẽn-noog a woto ka tog ne kõb-wẽng wala a Yamyɩɩd ye.
Nebã sɩd wʋk-b lame n tɩ lob mogrẽ wã.
Naabã ne a zakã rãmb fãa kell n yii dũni woto.
Tẽngã rãmb yaool n yõd n yãa taaba,
n dɩk a Yamyɩɩd n zaoolg naamã geer zugu,
t’a rɩ naamã bãmb sʋka,
t’a yaa bi-yẽesg sẽn tar yam.
A yaa beoog biiga.
 
Zʋg la zem-zem.
Naam buudã fãa segd n dɩɩ ne zemsgo.
