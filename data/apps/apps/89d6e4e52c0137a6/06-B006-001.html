6 Soaamb yʋ-baoore.
Soaamb dɛɛmb n wa n ki,
tɩ b rat n maan a kʋʋre.
Soaamb kẽngame n tɩ yeel a reem-dãmbã tɩ kʋʋrã daare,
yẽ na n zomba katr n wa.
T’a reem-dãmbã yeel-a t’a boog a yʋ-baoorã.
T’a yet tɩ b bas tɩ b na yã.
A sẽn yik be,
a pa kul ye.
A yaka a katr yirã n yeel-a:
- M ba Katre,
yãmb miime,
mam dɛɛmb kʋʋr la a yopoe.
M na n bõsame tɩ y wa yãag-ma.
Rɩɩb na zĩndi,
rãam na gãande.
Sãmbg kae ye.
Katr sẽn wʋm dẽ wã,
a yã-raoogã sẽn ya wala kurg naoorã tol n kelmame t’a yet tɩ Wẽnd na kõ-d kʋʋrã raar ne laafɩ.
Kʋʋrã daar yibeoog pĩnda,
Soaamb yikame n bao tãnd n pãb n wʋlg n be a rũmdi,
n zĩ a roog noore.
Pa kaoose,
la a katr sẽn be waoongẽ,
n yet t’a yik tɩ b kẽnge.
Tɩ soaamb yeel-a:
- M ba Katre,
yellã pa zems ye.
Mam paama sãmpogre.
Mam pa tõe n kẽn ye.
Yãmb pa ne mam dũmdã sẽn mod n zãensã sɩda?
Katr sẽn wʋm dɩɩbã kibarã,
kʋʋrã kẽnd lebga tɩlae ne-a.
A yeelame tɩ rẽnda b modg n kẽng bala.
La sẽn ya woto wã,
bɩ soaamb zomb yẽ tɩ b kẽnge.
Mik soaamb ra sɩd segla a menga.
A yik n dɩka gaare,
n na n ning katre.
Tɩ katr sok tɩ yaa bõe la rẽ?
Tɩ soaamb yeele:
- Yaa sẽn na yɩl tɩ bʋkd yãmb poorã wɛ.
Tɩ katr yet tɩ sã n ya boto bɩ a ningi.
Tɩ soaamb le rɩk salbre,
n na n ning katre,
t’a le sok tɩ rẽ me yaa bõe?
Tɩ soaamb yeel-a tɩ bi-kãseng wala katr kõn kẽnd t'a pa wagend kõbr ye.
La katr sakame t’a ning salbrã.
Katr wa n nee soaamb sẽn sẽbd a naoã sẽba.
T’a le soke:
- Wã me le yaa bõe yɛsa?
Tɩ soaamb yeel-a tɩ yaa sẽn na n lɩgemd yẽ lʋgã.
Rɩɩbã tẽeb sẽn be yalem-daoogã zugẽ wã,
a pa ne tɩ soaamb mams-a-la ne wed-moaag ye.
Rẽ zuge masã,
a kẽeme n maneg n ning fu-paala,
A n wa yi n yɩk n zomb katre,
n yet tɩ b loog masã,
tɩ katr sɩd dɩk sore.
B sẽn wa n poog tengã,
soaamb ninga katr sẽba,
t’a kʋɩ tĩiga,
n ya burga-burga-burga,
n pasgd tẽngã,
n dabd kʋ-yirã.
Nebã sẽn yã woto wã,
b fãa tʋka bʋʋre,
n yete:
- M ba Soaamb wa yã,
a zomba katre,
ad a sɩd yaa raoa!
Yaa rao tɛke!
A sẽn ta wã,
b reega katr n loe ne zãn-daoogo,
sɩmande wã,
n yaool n tall soaamb n kẽes zakẽ,
n bao rɩɩb n kõ yẽ.
Soaamb wa n tẽega katr yelle,
n kɩt tɩ b wʋk kõabã n yi n zam-a.
Kell n yɩɩ woto tɩ,
zaabr ta.
La soaamb mii vẽeneg tɩ katr sẽn n pa paam n dɩ n tɩgã,
kulbã pa na n yɩ,
nana ye.
T’a na n maan dabaare.
A yikame n pãensdi n yita,
la a gomd a yembre:
- Ɩye !
Tɩ m yaa rɛɛm yĩnga,
mam wed-moaag la kʋʋda?
Yell a woto sakd sɩda?
Pa saagd ye.
Ayo.
Sẽn na n yɩ,
n na n yɩ.
Mam pa sak ye.
Katr wʋma soaamb goamã fɩlʋ,
n bool-a n yet t’a kolg n togse.
- Yaa bõe n maane?
Tɩ soaamb togs-a tɩ b yeelame tɩ yẽ sẽn ya reem-kãsengã yĩnga,
yẽ wed-moaagã la b kʋʋd n dʋk reemã.
Tɩ katr yeel-a t’a yols wĩirã bilfu.
Tɩ soaamb sɩd yols wĩĩrã,
n lebg n kẽ.
Katr wa n wʋma bʋʋr sẽn tʋkd zakẽ wã,
t’a yet t’a ki ya.
A sẽn wẽ fuss,
wĩirã ﬁsgame t’a wudgi,
n zoe n kẽ weoogã.
A sẽn t’a põsẽ wã,
a tɩ bẽda soaamb sẽn na n tũ sor ning n kulã n gũud-a.
Zĩig sẽn wa n maag zãnga,
soaamb dɩka sor n fɩɩndẽ la a kuiisẽ.
A sẽn wa n ta katr sẽn da be zĩig ningã,
katr yek-a lame,
n modg-a t’a rʋ tɩɩga,
n yeel-a t’a kao raad n wa t’a sẽ-a.
Sẽn maand n be bɩ ?
Tɩ soaamb sɩd dʋ n tar raadã kaoobo.
A wa n yaasa kuu,
n wa yeele:
- Ãa?
Yaa ka bɩ ?
Tɩ katr yeel-a:
- Bõn yoogã!
Kao raadã tao-tao la f sig ka ne f bʋʋrã.
F yet tɩ f tar rabaar la rũndã yẽ,
fo ki yã.
Soaamba le wa n tool n yeelame:
M ba Katr bɩ bõe?
A bee ka.
La sasa-kãngã,
rabeem yõka katre,
t’a sok tɩ yaa bõe.
Tɩ soaamb yeel-a:
- Yaa yelle.
Kʋʋrã rãmb sẽn pa paam yãmb kʋ-yirã,
b yiisa kom-bi-bɩɩs tɩ b wat ka sẽnẽ.
Ade:
goabga,
yaa bug-raad rãmba,
rɩʋtgo,
yaa kãna.
Sẽn são-são,
yaa tɩrga.
Be yaa ra-bãan rãmbã.
Yãmb sã n dat n põse,
rẽnda y yi ra-bãanã rãmb nengẽ.
Mik ra-bãanã yaa pʋ-paall sẽn nan tuki,
tɩ beoosã la raadã tond yãyy.
Katr kell muma a ninã n na n kẽ-a.
A wudgdame n tɩ fão beo-kãngã n tʋk n lʋɩ kõe,
n tik n yik n yeele:
- F lub yã,
la f kõn dɩk ye.
A sã n yeel woto,
rẽ t’a le loogame.
A talla woto,
n wa kell n tɩ lʋɩ n ki,
tɩ soaamb sigi,
n bao gõos n lud-a,
la a bas n looge.
Soaamb yel-baoor la a yʋ-baoor n sat bɩ ?
A sẽn loog be,
a tɩ moona gʋga,
la a yel nebã tɩ yẽ tara tão-tɩ-põog tɩɩm.
Gʋgã raar yibeoogo,
yẽ n lʋɩ taoor n tar faoodg-faoodg,
tɩ nebã pʋgda.
A sẽn wa n kolg katr sẽn kiẽ wa,
a kɩtame tɩ kẽer kẽng rɩʋtgo,
tɩ kẽer kẽng goabga.
A Sẽn ta Katrã la a sẽn yãag a tãpã n yi-a loro,
n bas n zõond n kelem tɩ nebã fãa zoe n wa ges tão-tɩ-põoge.
Nebã sẽn zoe n wa ta,
b sɩd.
mika zũnzũy sẽn tar yĩgbu.
M ba Wãmb no-tʋʋn-nedã sẽn yã rẽ wã,
tao wala m noaag n yeelã t’a tɩ yeela we-naaba tɩ soaamb tara tao-tɩ-põog tɩɩm.
Tɩ we-naab yet tɩ soaamb modg t'a paam tɩɩmã.
Soaamb sẽn mik tɩ yaa woto wã,
a yeela we-naab tɩ tɩɩmã sã n na n dʋge,
rʋkã yɩg yaa sʋ-beelle,
pĩig kugri,
la wãamb zugu.
Soaamb kaa sʋ-beellã,
n dɩgl kugrã,
n yaool n yeel wãamb t’a kolg ne a zugã,
t'a rogɩ rʋkã.
Soaamb sẽn widg bugmã,
wãamb zugã sɩnga wɩngre,
t’a vurg bilfu.
Tɩ soaamb yeel-a t'a bas zugã sɩɩ,
la a ra maan n wa sãam tɩɩmã ye.
La sẽn zabdã.
Wãamb wa n kong n yikame n kʋɩ tĩiga,
tɩ rʋkã lʋɩ,
tɩ b rig-a tɩ ka tol n paam-a ye.
Tɩ soaamb yeel we-naab tɩ tʋʋmdã sãamame.
