8 M ba Katr kãoongo.
B sã n wa gomd m ba Katr yell fãa,
yaa sẽn na n gom a yalemdã yelle,
bɩ a yã-raoogã yelle.
Nebã fãa pʋs n ninga b yamẽ wã tɩ Katr yalemdã yaa wala b wʋlg n so-a lame,
t’a koko-raoogã yaa wala kurg naoore.
A sɩd nonga rɩɩbo,
la mik a tara rabaar me.
Katr n wa n tar a kãoongo,
n yõk-a n kʋ n maneg n kʋɩɩs-a,
n yaool n bao zĩig n bĩng-a.
Mik yaa yam.
Pʋg-yãang me n da be tẽng a ye,
n vɩ a ye,
ne a baaga,
a Gãre.
Pʋg-yãangã ra yaa rakãagre.
Noose,
kĩini,
bʋʋse,
piisi,
fãa,
a tara.
 
Daar a ye masã la katr yik yã,
n pẽgen a kãan-koɛɛngã,
n dɩk sore,
n dabd pʋg-yãangã yiri.
A sẽn ta wã,
a pʋʋsa pʋg-yãangã sõama-sõama,
n yaool n yeel-a:
- M ma sõngo,
ad m dat n bõs-y lame yaa,
tɩ y reeg m bũmbã n bĩng-m tɩ m kẽng la m wa.
Tɩ pʋg-yãangã yeel-a tɩ yell ka be ye.
A sɩd loogame n kẽnge,
n tɩ kaoos bilfu,
n lebg n wa.
Pʋg-yãangã kẽeme n dɩk a kãoongã,
t’a na n lebs-a.
La katr yeelame tɩ pʋg-yãangã kell n bas be nanda.
A loogame n tɩ maan rasem a tãabo,
n le lebg n wa,
tɩ kãoongã ket ne pagã bala.
La baraarã,
a le basame n looge.
Talla woto,
tɩ raar a ye masã,
pʋg-yãangã baag tʋk katr kãoongã n wãbe,
tɩ pʋg-yãangã pa bãng ye.
Katr sẽn wa rẽ zugẽ masã,
la pʋg-yãangã sẽn yeel-a :
- M biig sõngo,
ad yaa yelle !
Mam sẽn da tar fo bũmbã gɩʋbl la m sẽn tar a gɩʋblgo.
La ka võor ye.
Fo sẽn mi n wat ka wã fo ka mi n yã baag sẽn gãe ka sɩda?
Ad a Gãr rɩka bũmbã.
Tɩ katr maag a yĩng n soke:
- la baagã sẽn mi n gãe ka wã yaa ãnd baaga?
Tɩ pʋg-yãangã leoke:
- Hũmmɩ.
Yaa mam baaga.
T’a le sok n paase:
- La kĩinã,
noosã,
bʋʋsã la piisã sẽn silgd woto wã yaa,
yaa ãnd n so ?
Tɩ pʋg-yãangã yet tɩ yaa yẽ n so fãa.
Tɩ katr la a sũurẽ.
A sẽn da ratã la woto.
Rẽ la a yeel yã:
- Woo.
Rẽnd sẽn lebg woto wã,
a Gãr tara mam samd wɛ?
Ay!
La yell kae ye.
Bal yaa,
baag rɩ samde,
a zu-soab na yao wɛ.
Wãb kãoong ronda kãoongo.
A pa gom n sa la a be pʋg-yãangã kãoong koomdgẽ,
n tutẽ.
Vẽtembeeog t'a le waame,
n le yeel pʋg-yãangã:
- Baag rɩ samde,
a zu-soab n yaoode.
Wãb kãoong ronda kãoongo.
N le kasg kãoong a ye n looge.
A talla woto,
n wa sa kĩinã fãa pẽss.
A sẽn bãng t’a sa kĩinã,
a wa n yeelame:
Baag rɩ samde,
a zu-soab n yaoode.
Wãb kãoong ronda noaaga.
Rẽ t’a yõka noaag n tutẽ.
A le maana woto n sa noosã,
n long piisã.
Katr kell n tuka a so-buka,
n wat zaabr-zaabr fãa masã,
n yõgd pʋg-yãangã rũms n wãbdẽ.
Pʋg-yãangã sũur ra sãama hal wʋsgo.
A ra basa taal la bala.
A pa tar yellã tɩɩm la !
Daar fãa,
a tara yãbr bala.
La Wẽnd pa naand yell n pa ning a tɩɩm ye.
 
Daar a yembre,
we-naab wa n loogdame,
n yã pʋg-yãangã sẽn kʋmde.
T’a sok-a :
- Pʋg-yãanga!
Yaa noog tɩ y zĩ ne yɩɩr woto ?
- Ad yaa yell n paam-m.
Katr n wat n yõgd m noos la m piis tɩ m pa mi m sẽn kẽedẽ ye.
A sẽn togs yellã n sa,
la bõnyẽegã sẽn yeel-a :
- Ad d sẽn na n maan a soaba.
La pʋg-yãangã sɩd pa kɩɩs ye.
A maana wala bõnyẽegã sẽn wilgã.
Zaabr sẽn wa n ta,
tɩ zĩigã lebg lib-libi,
wala baag-bãng-m-soabã sasa,
katr sɩd le waame,
n le sɩnge:
- Baag rɩ samde,
a zu-soab n yaoode.
Wãb kãoong ronda peosgo.
Rũng n dag n wẽneg n loe ne zãn-daoogo,
yambẽ be.
A sẽn yeel woto wã t’a bee rũngã lokrẽ bala.
La yẽ sẽn da ka mi wã yaa,
bõnyẽeg kɩtame tɩ pʋg-yãangã loe yẽ mengã ne zãn-daoogã.
La sẽn ya likã,
katr pa ne sõama ye.
A sãmbame tɩ yaa peosgo t’a lok-a n tɛt-a n tutẽ,
n kẽed weoogã n yet t’a leb n paama a zaabr dɩɩbo.
A sẽn wa n na n bãngã,
yaa bõnyẽeg sẽn tir n yaase.
Katr sẽn wẽneg n maag a yĩng n gese,
a mikame tɩ yɩɩda peosgo:
yaa we-naab menga.
T’a wẽ fuss,
n kʋɩ tĩiga,
n fãood beoosã la tuudã,
n baood a menga.
Yɩɩ woto tɩ katr na n lak n bas pʋg-yãangã.
