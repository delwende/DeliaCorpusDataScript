9 Ad a Baag zaba ne a yirã rãmba.
Daar a yembre,
baag zaba ne a yirã rãmba.
Zabrã yɩɩ rɩɩb poorẽ.
Baag yeelame tɩ zakã rãmb sã n na n kõ yẽ rɩɩbo,
b basdame n dɩ n sa n yaool n kõ yẽ t’a rɩ.
Rẽ me,
b pa sukd zẽed n kõt yẽ ye.
Daar fãa,
yaa sag-wẽema,
wall sagb sẽn wãds-wãds n los koomẽ.
Woto yĩngã,
a yik n zoe n kẽnga weoogẽ wã n tɩ vɩ be.
A tɩ mika we-baag be,
n yõg zood ne-a,
tɩ b yiibã be be,
n yõgd rũmsã n wãbde,
tɩ b vɩɩm ya-b noogo.
Daar a yembre,
b wa n nee saagã sẽn kʋɩ n limsi,
tɩ b tar sẽm-sẽm-sẽme,
n baood zĩig n na n soonde.
Zu-noogo,
b yãa tãng boko,
n zoe n kẽ be.
Zu-buko,
katr doogo.
Katrã me zoee saagã,
n tar burga-burga n wat a roogẽ.
A sẽn ta n lɩk bal la a sẽn ne bãmbã sẽn dõbe.
T’a la n kaase,
n bas n yet tɩ Wẽnd kũun yɩɩd baoobo.
Sasa kãng tɩ yir baag tara rigb kob-kob-kobe,
n tol n zoe n kɩrg rʋʋd-koom la a sã bĩungu.
La a we-baaga yeela katre:
- B ba Katre,
yãmb gomdã yaa gõaag zugu.
Yaa sɩd bal pae !
Wẽnd kũun sɩd yɩɩd baoobo.
Ad a Baag zaba ne a yirã rãmba,
n dat n sɩbg a zu-soabã.
Yaa rẽ la a wat n na n yeel-y tɩ y maneg yãgre,
t’a tɩ peeg a zu-soabã niig n wa n kõ-yã,
tɩ y bĩng n tar n wãbd y yam.
Katr sẽn wʋm dẽ,
a sũurã yɩɩ noog zuddd.
T’a yeele:
- N-faa!
Yɩlem be.
Sã n mik tɩ yaa woto,
mam na n yik n sɩnga yãgrã maanegre.
La we-baag soka Katre:
- La saagã?
Yãmb pa zoet saagã ?
Y pa na n yaas t’a yooge ?
Tɩ katr yeele :
- Saaga ?
Saag kʋʋda katr la ?
Foom a we-baag mengã waa.
Rẽndame tɩ fo mengã yik n yãag a yir baaga,
tɩ y maan tao-tao.
Modg-y tɩ naaf ba a ye ra pa ye.
Peeg-y ne nag-bi wã fãa.
Haya!
wudg-y n kẽng-y la y wa.
Ra kaoos-y ye.
 
B sẽn bas katr n zãag bilfu,
laa yir baag sẽn kʋɩ tĩiga.
Yaa yir sor dɩkr bala.
Wã n le yas n pʋʋsd zoa wẽnd na taase?
Baraar tɛka,
yir baag pa le zab ne a zu-soab rɩɩb poorẽ ye.
A rɩta a sẽn paame,
n yetẽ meng tɩ rɩɩbã rɩta togem-togem.
Sasa-kãngã tɩ yaa a sẽn paam sagbã n dɩte tɩ maan bʋʋr ningã.
A sã n le kẽng weoog me,
yaa a tɩ kaag la a wa kɛ.
A yam pa le kõt-a t’a tɩ vɩɩnd be ye.
Saag ling-a me,
a zoet n wata yiri.
 
Moosã sẽn mi n yetẽ tɩ f sã n bas f rɩẽ yaoore,
tãmbeok la f gɩĩudã,
b pa yag ye.
Rat n yet tɩ fo sã n sãbs bũmbu,
f zug sã n pa yɩ noogo,
sẽn pa são rẽ la f na n tɩ rɩke.
