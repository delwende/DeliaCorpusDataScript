140 F sã n dat biig ma sagb n dɩ, dɩlla f zug yɩ gãngãooga.
 
141 F sã n dat wagdr n yõke, kɩt-a-la f kʋlen-biiga.
 
142 F sã n dat yũug n kʋ, f baooda no-kõbd n bẽ a noore.
 
143 F sã n deem ne biiga, a lɩkda f yõorẽ n peeb tɩ wɩɩga.
 
144 F sã n gãand tẽng n tʋbse, f tʋbsda f yãoogẽ.
 
145 F sã n kẽ saoog n pa yã kilsg bɩ f lok kalle.
 
146 F sã n kẽ saoog n pa yã kilsg bɩ f targ n leb poorẽ.
 
147 F sã n kẽnd kiu-kiu bɩ f zãms liu-liu.
 
148 F sã n kẽng tẽng n tɩ mik tɩ neb wẽeda gãngãa d ne gɛgt bɩ fo me saoodẽ la f kẽed gõosẽ.
 
149 F sã n kĩ ne bʋẽega, f nintãm sata raagẽ.
 
150 F sã n kʋ f tãnpĩiri, f to bi-bẽeg n kʋʋd-fo.
 
151 F sã n kʋ mam bʋʋga, naaf la f ronda.
 
152 F sã n laad ned t'a yaa rakõore, a wat n la-f la me tɩ f pag yaa pog-yãanga.
 
153 F sã n maan f meng wãamba, b sã n wa baood wãamba, yaa foo la b rɩkda.
 
154 F sã n maan yãnd tɩ sẽn kẽedẽ kaẽ, f kũum n são.
 
155 F sã n minim koabga, pis-nu yooda yam.
 
156 F sã n naag yãag n dɩ kazẽeg sagbo, a yetame tɩ f wa tɩ y sã kazẽeg bĩndu.
 
157 F sã n pa kʋ, f pa sɩɩgd ye.
 
158 F sã n pa mi tẽng kɩɩmse, f pa wẽed a bendr ye.
