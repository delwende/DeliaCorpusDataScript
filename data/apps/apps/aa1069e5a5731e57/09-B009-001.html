160 F sã n pa na n ning la-wẽdgẽ n dɩ bɩ f ra ning n kõ f to ye.
 
161 F sã n pa na n zɛ n bas ned bɩ f ra rɩ n bas-a ye.
 
162 F sã n pa na n zɛ n bas ned bɩ f ra rɩ tĩig-tɩɩm n bas-a ye.
 
163 F sã n pa na n zɛ n bas ned bɩ f ra yãgem n bas-a ye.
 
164 F sã n pa nong tɩ yak ki me, f rat t'a serg n bas raboogo.
 
165 F sã n pa sak sugr wẽnd yĩnga f wat n sak-a la zaalem yĩnga.
 
166 F sã n pa tar wagdr pãng bɩ f tʋk n yãag-a.
 
167 F sã n pa tõe n zomb f ba tɩɩga, bɩ f kolg n sɩɩs-a.
 
168 F sã n sak pidbu bɩ f saak tẽebo.
 
169 F sã n ta tengẽ n yã tɩ b pãbd gãngãad ne gɛt bɩ f me sao n kẽ gõosẽ.
 
170 F sã n tẽeg f bẽ yell bɩ f bugl loko.
 
171 F sã n tẽeg f zoa yell bɩ f rʋgl rʋko.
 
172 F sã n ta tẽng n mik tɩ nebã fãa kẽnda ne zut, bɩ f me kẽ.
 
173 F sã n ta tẽngẽ n wʋm yag-kẽgenga pa põore yaa zõanga.
 
174 F sã n tɩ ta tẽng n mik tɩ b pãbd gãngãad ne gɛto, bɩ f sao n kẽ gõosẽ.
 
175 F sã n togs bõang n sẽ f yẽdg n pãrgde.
 
176 F sã n tõdg wẽnd na kõ-f sugri, f reegda wẽnd na ko-f laafɩ.
 
177 F sã n tũud yũuga, f watẽ n wõba nem kãado.
 
178 F sã n vʋʋg ned yoore, f pag la a yõgda.
