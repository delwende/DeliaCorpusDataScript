4 Soaamba ne wobgo ne yemde.
Daar a yembre,
soaamb da baooda sõngr n na n tʋm a tʋʋm-kasenga,
n tɩ kos ninsaalb tɩ b wa sõng-a.
A yeel-b lame t'a na n kʋʋ yemd biig la wobg biig n maan rɩɩb n kõ-b tɩ b rɩ.
A sẽn pʋlem-b woto wã,
b fãa yeelame t'a yagdame,
tɩ bala yẽ a soaamb pa tõe tɩ yemsã la wobdã tũ yẽ raab ye.
Soaamb kẽngame n tn yã yemd n yeel-a :
« Kõ maam f biigã.
M na n wub-a lame.
Yʋʋmdã sã n vẽke,
m na tall-a n wa kõ-fo,
la wakat kãnga f na yã t'a bedrem na n yɩɩga foo».
Tɩ yemd sak n kõ-a a biigã t'a tug n wubi.
Soaamb loogame n tɩ yã wobg n yeel-a :
« Zĩig n be kaanẽ sẽ,
koomã tẽn-sʋka,
tɩ m sã n tall-f n kẽng be,
bɩ f sũur na n yɩ noogo,
bala rɩɩb wʋsg bee be.
F na n kõ-m-la f biigã tɩ m tɩ wub-a be».
A sẽn paam Wobg biigã,
a loogame.
Soaamb lebgame n tɩ ya ninsaalba,
n kos-b tɩ b maan tuʋmdã.
A kʋʋ rũms a yiibã koamb n kõ tʋntʋmdbã tɩ b rɩ.
Kiuug a yoob loogr poore,
soaamb wa n kẽnga kʋɩlgẽ wã.
" Hey,
yemde,
m waame !
Mosã,
kiis a yoobã loogame,
tɩ m dat tɩ f bao wĩir n wa kõ-ma,
wĩ-sõngo.
Sẽn ta kiis a yoob mosã tɩ f biigã pa wa ka wã,
la a sẽn lebg bedr wʋsgã yĩnga,
rẽnda m paam wĩ-sõng sẽn tar pãng n tall-a n wa.
Rẽ,
fo takd-a lame n lebs n kẽes koomẽ wã».
M ba yemd gãda wĩirã noor a ye n yaool n dɩk a ye wã n kõ soaamba.
Soaamb zoeeme n tɩ kõ m ba wobg noor a ye wã n yeel-a :
« Fo biigã bee ne maam,
koomẽ wã,
a kiis a yoob la woto.
Mam pa tõe t'a yi koomẽ wã ye,
yaa toog ne maam.
Mosã,
a pãng yɩɩda foo.
Gãd wĩ-kãngã n tak-a n yiis koomẽ wã».
A talla wobg n kẽng koomã noore,
n tɩ loe wobg yubl ne wĩirã.
N yaool mosã,
n tɩ loe wĩirã noor a ye wã ne yemd yubla,
n yeel rũmsã a yiibã tɩ b maneg n tae b koambã.
B yiibã taeeme :
yemd takdame,
wobg takdame.
Sẽn wa n beẽ,
a ye n wa n ya n bas taeebã.
Yɩɩ woto tɩ yemd paam n yã wobgo,
tɩ wobg me paam n yã yemde.
Wobg yeelame :
« Yaa wãn tɩ,
mam wa be ka n tat foo ?
Mam tat m biiga,
tɩ wa yaa yemde »!
La yemd me ra tata a biig la sẽn wa n tɩ yaa wobgã.
« Yaa boe n maan tɩ tond wa tat taab woto » ?
« Yaa soaamb n loe maam a Woto »
Rẽnd rũng fãa togsa a to a yellã.
Tɩ wobg yeele :
« Soaamb zãmba tõnd la d togame n subg-a.
Fo na n gũus-a-la kʋɩlgẽ wã tɩ mam gũus-a weoogẽ wã.
Fo tõe n kɩsa sɩd tɩ m sã n yã soaamb ka,
a pa na n leb n wãb yam-maas-kãngã ye».
«Tɩ yemd yeele :
« Fo tõe n kɩsa sɩd tɩ soaamb pa na n leb n tõog n yũ koom kʋɩlgẽ wã.
D na n yõk-a lame n kʋ.
Daar a yembre,
m ba soaamb wa n data yamd n wãbe.
A yii a bokẽ wã n yã rũn-kɩɩng zu-wanga.
A kẽe zu-wangã pugẽ tɩ b ka le mi sẽn ya a soab ye,
n tees wobg n kẽnd n dabda.
A sẽn wa n pẽneg-a,
wobg sok-a lame :
« Foo la ãnda »?
« Yaa maam ».
« Ând n maan foo Woto »?
« Sʋɩtãan n be,
sʋɩtãan meng-meng n be weoogẽ wã :
soaamba.
Yaa soaamb n maan maam woto.
La sẽn paasde,
a loba maam bẽd-yooko :
a yeela maam tɩ ned sã n dat n maan maam wẽeng tɩ mam sã n kelem vugr bala,
a soab lebgda wa maam.
Rẽnd rũndã tɛka,
ra le pẽneg maam ye.
Mosã,
m na n kẽe we-raoogã pʋg n pa bɛ n wãbd m yamdo.
« Wobg yaeesame n lak n zãag n leb kɛɛng n na n tɩ wãb a yamdo.
Soaamb maana Woto n paam n dɩ a rɩɩbo.
La,
ko-yũud wa n tar-a lame t'a rɩk kʋɩlgã sore.
Yemd sok-a lame :
« Foo la ãnda »?
« Maam ?
m yaa rũnga ».
« Yaa bõe n paam foo »?
« Yaa soaamb n maan maam woto.
A loba maam bẽdgo,
bala soaamb yaa sʋɩtãan meng-menga ».
A sẽn kelg woto wã,
rabeem kẽe yemde,
t'a tags a yamẽ :
« Ha,
mam sã n tɩ seg-a,
a na n maana maam wala a sẽn maan rũn-kãngã wã.
" T'a lis koome wa,
tɩ soaamb paam n yu,
t'a zu-loeesã fãa paam tɩɩm woto.
