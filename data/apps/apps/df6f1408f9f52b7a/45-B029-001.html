23 Kasem yam yɩɩda yãaga.
Yãag a ye n yeel a manga :
« B yetame tɩ nin-kẽem yam yuda yãag wakat buud fãa ».
Rẽ yĩnga,
a kẽngame n tɩ seg nin-kẽem n na n sõs ne-a la a bõos-a t'a sagl-a.
A taa nin-kẽemã nengẽ n yeele :
« Mam waame tɩ f sõng-m ne yam tɩɩm baoobo.
M waame tɩ f kõ maam yẽ soabã ».
Nin-kẽemã yeelame t'a tõe segla tɩɩmã n kõ-a,
la bũmb n dengd maanego :
Bi-pokã ra togame n kẽng weoogẽ n tɩ bao we-naaf bĩisim n wa kõ-a t'a yaool n tõog n segl yamã tɩɩm.
Nin-kẽemã yikame n kẽ a roogẽ n yi ne lɩng n kõ-a.
Bi-pokã ra miime t'a ra tõeeme n yã we-naafã weoogẽ,
bãk sẽn beẽ.
Be,
a na bao yam ning a sẽn na n maaneg n yãk bĩismã.
A kẽnga weoogẽ wã n tɩ yã zĩig ning sẽn da tõe n yɩ rũngã soaag zĩiga.
T'a lebg n kuil a yiri,
n tɩ bao yamsem n tɩ rɩgl we-naafã sẽn da tõe n tɩ gãandẽ zĩig ningã.
We-naafã sẽn wa wã,
a mikame yamsmã,
t'a rɩ.
Mosã,
bi-pokã mii zĩig ning takɩ a sẽn tõe n tɩ yãẽ rũngã,
bala a ra lebgdame n wat n baood yamsmã a sẽn nong sõma wã.
A segla a menga,
n dɩk a lɩng n loog weoogẽ wã.
We-naafã sẽn yã-a wã,
a tees-a lame n dabd n na n tɩ kõs-a ne a yɩɩlã.
Bi-pokã solga a meng toe-kẽeng poorẽ.
We-naafã baoome n na n kõs-a t'a yɩɩlã sud toɛɛgã.
Bi-pokã rɩka a lɩngã,
n pẽ bĩismã n tall n tɩ kõ nin-kẽemã.
A sẽn ta ne we-naafã bĩisim,
nin-kẽemã sok-a lame :
« Fo maana a wãn n paam bĩismã n yãke »?
Bi-pokã togsa yam ning a sẽn tall n paam n yãk we-naafã bĩismã.
Tɩ nin-kẽemã yeele :
« Yaa yam-kãngã buud la mam tɩɩmã tõe n kõ-fo.
Bĩismã fo sẽn yãk we-naafã nengẽ wã,
yaa rẽ la f tog n yũ.
Yell ning sẽn wa-a fãa,
fo na n tõogame n paam a tɩɩm.
Fo sã n tall yam n tõog n paam bĩis-kãngã,
fo na yã yam wakat buud fãa n weel f zu-loeese ».
.
