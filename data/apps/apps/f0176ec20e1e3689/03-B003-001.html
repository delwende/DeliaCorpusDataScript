3. Biiga a Ka-yelle
Rao n wa n doga a biig n pʋd a yʋʋr t’a Ka-yelle. A Ka-yell da yɩɩ nimbãanzoeta. A da waoogda tẽngã raop la b pagb fãa la a get koams-rãmb yelle.
Daar a yembre, a wa kẽnga weoog n tɩ yã wãoore sẽn yaa zoang t’a yĩngã fãa pid ne noad n pelge. La a Ka-yell maana a tʋʋmde : a zoe-a nimbãaneg n tall-a n wa a zakẽ n tɩbs t’a sãooge. La kiuug a yiib loogr poore a sẽn sãaog n sa, a yikame masã n kẽnd n tɩ sõsd ne tẽngã naaba. La a wa n yeela naabã t’a sã n pa gũus a meng ne a Ka-yelle a na n kʋ-a lame la reeg a naama.
La naabã yeela wãoorã : « A Ka-yelle sẽn be ka tɛka a zɩ n paoog maam ye. A waoogda nebã fãa, a pa tar a toor yell ye. A nan pa maan bũmb sẽn sek m kʋ-a ye. Nebã meng sãn wʋm yel-kãnga b pa na n kõ maam bʋʋm ye. Woto wã mam na n maan a wãnã. »
Wãoorã leok-a lame: « Dẽ pa yell ye. Rõogã sẽn be kʋl-kasenga sʋkã woma biisi. Bool-a n tʋm t’a kẽng n tɩ yãk rõogã bil n wa ne, a sã n tõdg bɩ f maan-a wa f sẽn date. » La naaba sɩd boola a Ka-yelle n tʋme.
La a Ka-yelle sɩd kẽngame n tɩ ta n gilimd kooma n ka tõe n kẽ n yãk rõoga bil ye. La Kẽeg ne Kur wa n kolg n sok-a lame tɩ yaa bõe t’a wa tar koomã noor gilgri ? T’a Ka-yell yãk yellã võore n togse. La Kur yeela kẽeg t’a kẽng n tɩ yãk rõogã bil n bas tɩ lui kooma pʋg tɩ yẽ na dɩkame n wa kõ a Ka-yelle. Sɩd yɩɩ a woto t’a Ka-yelle paam rõodã n wa kõ naabã.
Wãoorã bʋʋga naabã yeele : « Fo sã n dat-a bɩ f gẽdg koodã biisã taab ne wamde n yaool n bool-a n kõ-a t’a tũus-b wakat a yembr pʋgẽ bal n wa kõ fo.» La naabã kɩtame tɩ b bao sĩini, bi, ki, sũma, nanguri (sũmkaam) bɛnga la kood a taaba biis n gẽdg b taab n yaool n bool a Ka-yell n kõ t’a reeg n tũus n wa ne. La a Kayelle deega wamdã ne koodã biis ne nintãm n yet wã la bõe n tɩ zĩi n ka mii a sẽn na n maan bũmb ning ye. La yẽsã, salsaasã ne gũurã naag a taab n wa sok a Ka-yelle t’a yã yellã n togs-ba. La b reega koodã ne wamdã n tũus n bak koodã biis ne a to zãng n dɩk n kõo-a t’a tɩ kõ naabã.
A Ka-yelle wa n bãngame tɩ yaa mu-na-fɩka (a sãana) n dɩkd yẽ zugã n wẽed ne naabã la yẽ sã n bas n deeme n pa bao yam n kõo a menga a na n basa dũniã. A wa n baoa Vũnun-vũusã wʋsg n kẽng n tɩ ning naabã ba kabr pʋg n yaool n wa yeel naab t’a segleg a meng t’a baoã vʋʋgame n yik n wat ne sodaas ne zab-teed n dat n wa reeg a naamã n dɩ. La naabã tʋma neb tɩ b kẽng n tɩ ges a baoã kabrã. B sẽn kolge, b wʋmda vũnun-vũusã vũuga, tɩ b zoe n wa togs naab t’a sɩd bao a menga sãn pa rẽ a baoã sɩd wata ne ziiri : bɛnda, gãngãad n paas sodaas ne bugraad n dat n zab n deeg a naamã. Naabã makame n kong n bool a Kayell sok-a tɩ la woto wã yẽ maand a wãnã? T’a Ka-yelle yeel-a bal tɩ yel-kãnga tɩɩm yaa zoang sãoore. La wãoorã sẽn da be be wã yɩɩ tao tao n yeele : « ad wãoor a to n be a bõnd yirã.» Tɩ b yeel-a : «  La fo sẽn be ka wã. » Tɩ b be yẽ yõkre.
Ta a Ka-yell yaool n na n paam a meng n vʋɩɩnd ne laafɩ.
Nin-wẽng menga bẽdg n yõkd-a.
