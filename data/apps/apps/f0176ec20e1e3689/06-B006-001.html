6. Tãoos a ye kɩbare
Tãoos n wa n tɩ ti pagdere koom noor n gũusd we-rũmsã sẽn wat n yũud kooma n tãoodẽ. La daar a ye, a wa n kẽnga zĩig wã n na n tɩ tãoose. La a wa n zẽk a neng n yã kĩnkĩirg sẽn zĩ n sõt a ligdi. T’a sok a menga : « Mam tãood-a lame n kʋ la m sig n tɩ rɩk ligdã bɩ ? » La kĩnkĩrgã gir a zugu. Bɩ : « M na n tɩ sõng-a lame n sõd ligdã t’a yãk n kõ maam ? » Tɩ kĩnkĩirgã goos a zugu n yet tɩ õo hõo.
Raoa kẽngame n tɩ sõng kĩnkĩirgã n sõd ligdã n sa. La kĩnkĩirgã yãka ligdã n kõ-a t’a tõdg n yet t’a pa rat ye. La yẽ sẽn dat bũmb ningã ya a bãngrã. La kĩnkĩirgã yeela raoã : « Fo pa tõe n zã bãngrã ye. » La raoa yeelame t’a tõeyãme. Kĩnkĩirgã sɩd mak n kongame n kõ-a la nug bĩnga n yaoool n yɛɛl-a t’a ra wa saag n togs ned ye, bala a na n kiime.
Tãoosã paga me da yaa nifr a ye. Daar a ye, pagã wa n da wenda ki neerẽ. La noosã waa n dat dɩɩ kiwã. La noraoogã yeela noyãangã t’a leb pagã goabg nifã sẽn ka ne wã sẽ, n liib pagã t’a peng ki wã ne wamdã n lub tɩ b paam n dɩ ki wã. Tɩ tãoosã zĩ n kelgdẽ. Noyãangã sɩd leba pagã nug goabgã n liib-a t’a peng ki wã n dʋʋg tɩ b sɩd rɩ. Pagã sɩdã da zĩime n getẽ la a laadẽ.
La pagã soka a sɩdã a laadã võore, t’a sɩdã yet tɩ pa bũmb ye. (Bala a sã n togse, a na n kiime). La pagã yeelame t’a sã n pa wilig a laada võore, yẽ na n wʋk a teed n kul a ba yiri tɩ sa. Raoa makame n kongame n togs-a. Dẽ poore raoa kiime. La tẽngã rãmb tuu kabr na n mum-a t’a a zoa a ye tõdg n deeg kũuma n dɩk-a n kẽ weoogã n bao zĩig n tɩ bĩng n yaool n bao zĩig n solg n get kũuma. La dʋgr bil n wa na n dɩ-a. A sẽn kolg n gok kũuma la a sẽn rok n lʋɩ n kõe. La dʋg naabã wa taame n yãk tɩɩm ne zʋʋr a korg pʋg n sɩɩs dʋg-bilã n n yaool n yɛɛl-a :  « Fo sãn mii n yã rɩɩbo, bɩ f bas tɩ rʋg naab gok tɩ f yaool n goke. Fo sã n mii n yã rɩɩbo, bɩ f bas tɩ dʋg naab gok tɩ fo yaool n goke. Fo sã n mii n yã rɩɩbo, bɩ f bas tɩ dʋg naab gok tɩ fo yaool n goke. » naoor a tã tɩ dʋgrã vʋʋge.
Dʋg naab kẽngame masã n tɩ ta na n dɩ kũuma. La raoã yɩɩ tao tao n kẽng n tɩ dig-a la a rɩk zʋʋrã n kẽng tɩ ta n pĩng kũumã n yeele : « Fo sã n mii n wʋm gomde, reng n togs f zoa la f yaool n togs f paga. Fo sã n mii n wʋm gomnde, reng n togs f zoa la f yaool n togs f paga. Fo sã n mii n wʋm gomnde, reng n togs f zoa la f yaool n togs f paga. » Naoor a tã tɩ kũuma tĩs n vʋʋge.
Yam dɩkda f to nengẽ.
