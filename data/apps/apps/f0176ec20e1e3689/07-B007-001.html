7. Baag ne m ba Boɛɛga beem sɩngre
Sẽn deng tɩ Baag ne Boɛɛg lebg beem, b ra yaa zoodo. La ba-Kãnga ra tara yam n yɩɩd baasã fãa. La sã n yaa ne m ba Boɛɛg yẽ, yaa bʋyãansã boblg bala. Tɩ b yet m ba Boɛɛg tʋʋmd yaa bʋ-yãansã boblgo la yamã pa yɩɩd a yõ-rooga woglem ye.
B yiibã fãa waa n tũu taab n tog sore. B sẽn wa tar kẽn weoogã pʋga, yaams la koyũud waa n yõk-b lame, la b yãa tɩɩg sẽn tar maasem tɩ b kẽng n na n tɩ vʋʋs a tẽngre. La b sẽn ges b taoore, b yãa bulga ne koom (kʋlga tɩ b fãa loog n ta. La Bulgã sẽn da zulum bilf yĩngã, b dat koom n yũ la, la b sã n kẽ ãnna n na n yiis bãmba. La Baag yeela m ba Boɛɛga : « D kẽ n yũ koomã, mam tara yam d sẽn tõe n maan n yi ». Tɩ b fãa sɩd be kõome. B sẽn wa n yũ kooma n tɩge, m ba Baag yeela m ba Boɛɛga : « Tẽeg f naoã n teeg bulgã n maneg f yublã ne f yɩɩlã n tees tɩrg wa radg tɩ mam dʋ n tag n yi. Tɩ mam sã n yi n sa bɩ m tak foo marsã n yiisi ». La Boɛɛg sakame n tẽeg a meng tɩ Baag dʋ-a n tag n tũ n yi.
M ba Baag sẽn ta yɩng n sa, a yɩɩ tao-tao n yeel Boɛɛgã : « Fo sã n tar yam wa fo sẽn baood pagbã toto wã, fo ra togame n tags tɩ tõnd yaool n kẽ Bulga pʋgẽ.
Maam yẽe maana yam n fãag-m-menga ; Fo me bãng f sẽn na n maaneg n yi.
Wẽnd na kõ-d nindaare.
Fo sã n na n tʋm tʋʋmde, bao n bãng a baasgã nanda.
